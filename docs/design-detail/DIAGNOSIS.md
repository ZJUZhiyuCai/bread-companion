# 面包 · 细节诊断（基于 aa82f78 与四张 Mock 截图）

> Claude Opus 5.5，2026-11-05。只读了本目录的代码和 `reference/` 的四张截图，没有浏览器，下面的判断来自截图像素和代码推算，没有实际渲染验证。
> 截图都是 Mock 夹具：回复是规则演示，语音转写不可用，所以四张图里的电话都处在“现在打不了电话”的状态。线上一旦 ASR 掉线，用户看到的就是这几张图的样子。

方向不动：照片毛绒、完整睁开的玻璃眼、红色 Blender 座机、浅色布景。下面只列“还不够精细、自然、顺”的地方，按对观感的影响排序。

---

## A. 看得见的瑕疵

### A1. 不能打电话时，红电话变成一只半透明的棕色电话 ★★★

- **截图**：`home-1440` 里电话是灰棕色，左上角能透过机身看到面包右侧的绒毛（电话叠在面包脚前）；`chat-1440` 侧栏、`chat-390` 的“打电话”胶囊、`home-390` 同样是棕色。
- **原因**：`.phone-door.is-blocked .phone-door__poster / .phone3d / .phone-door__phone` 都是 `opacity: 0.8; filter: saturate(0.3)`，胶囊是 `saturate(0.2); opacity: 0.7`，SVG 回退是 `saturate(0.3)`。
- 通话页已经修过同一个问题，`globals.css` 里的注释写着：“Taking most of the colour out turned the lacquer a muddy brown — a different object”，那边改成了 `saturate(0.62) brightness(0.97)`。首页、侧栏、胶囊、SVG 回退没有跟上，现在一个页面里有三套“不可用”的调色。
- **后果**：已认可的“协调的红色 3D 座机”在最常见的降级状态里变成另一件物体；半透明则让摄影布景里出现一个“幽灵”，和照片质感冲突。

### A2. 侧栏和胶囊在不可用时变回“虚线纸板” ★★

- `chat-1440`：侧栏电话外面套着一个虚线圆角框；`chat-390`：胶囊变成虚线边、灰底。
- 设计原稿明确说电话行“No card, no enamel … only shows its edge under the hand”，可 `.is-blocked` 时又画回了虚线框。虚线框是表单占位符的语言，正是要避开的“廉价纸板 + 图标感”。

### A3. 侧栏电话说明孤字换行“吧” ★★

- `chat-1440`：“现在打不了电话，先打字 / 吧”。中文短标签在 140px 左右的栏宽里按字断行，句末单字落到下一行。
- 同样的风险在 `.companion__bubble`（面包的字幕）、胶囊提示里都存在。

### A4. 手机聊天顶栏溢出，“结束”被裁掉 ★★★

- `chat-390`：右侧“结束”胶囊贴着屏幕边缘被切掉一截。
- 推算：内边距 20 + 头像 30 + “面包”字标约 50 + “AI · 演示”约 79 + 两个工具键 90 + 停止/结束约 113 + 间距，约 400px，超过 390。`≤360px` 已经有隐藏字标的规则，但 375–440 这一档没有覆盖，而这正是主流手机宽度。
- “结束”是用户离开今晚的唯一入口，不能被裁。

### A5. 光池有硬边 ★★

- `home-1440` 左缘、地面上方有一道弧形的亮边。
- 原因：`.entry__hero::after`、`.nook__table`、`.cstage::before` 的径向渐变半径超出了自身盒子（例如 `50% 50% at 40% 46%`，左边和上边都超出），再被盒子边缘或 `border-radius: 50%` 裁掉，在渐变还有 20% 左右亮度的位置切出一条边。另外，线性衰减的径向渐变本身就会在边缘形成可见的“锥形”马赫带。
- 光应该没有边。这类边在高质量屏幕上很显眼，也最能暴露“这是 CSS 不是光”。

## B. 状态与动效：不够顺的地方

### B1. 状态台词是“硬切”，不是“换一句话” ★★★

- 侧栏字幕 `.companion__bubble`、手机条 `.perch__say`、通话标题 `.callroom__phase-text` 都靠 `key={line}` 重新挂载：旧句子在同一帧消失，新句子从透明淡入（侧栏还带 5px 位移）。中间有一段空白，看起来是“闪一下”。
- 这些句子跟着真实状态变，而状态会在短时间内连续跳：用户开始打字（`我在。` → `慢慢写，我等你。`）、清空、发送（`慢慢写` → 可能一两帧的 `我在。` → `嗯，让我想想…`），通话里每一轮都要换三次标题。每一次都是一个小的“加载突变”。

### B2. 首页英雄区在能力检查返回后会跳 ★★

- `.entry__hero:has(.phone-door.is-blocked) { margin-bottom: 1.75rem }`：能力检查返回“不可用”时才加这段外边距。桌面上英雄区垂直居中，所以面包和电话会整体上移约 14px；手机上下面的标题会下移 28px。
- 电话海报是高优先级加载，通常比 `/api` 返回早，所以这一跳是看得见的。这条规则原本是为了给可能换行的原因预留空间，但实际只有两种原因文案，每种都不超过 14 个字。

### B3. 消息旁的小脸在朗读时以 0.9s 节拍上下抖 ★★

- `.bread-mark[data-state='speaking'] { animation: bob 0.9s infinite }`：朗读一条回复时，旁边 30px 的小脸一直在跳。
- 这正是“频繁抖动”，也违反了样式表自己的规则（“Nothing loops on a fixed beat to look busy”）。文字下面的朗读标记已经说明了“在念这句”。

### B4. “在想”三个点在跳 ★

- `.dots span` 是 1.4s 循环的 `translateY(-3px)`。每一轮回复都会出现，是对话区里唯一持续上下跳的东西。

### B5. 通话里的长时间等待只有沉默 ★★（与本轮“5 秒长尾”直接相关）

- `thinking / transcribing` 时，标题是“嗯，让我想想”，身后的光在呼吸。2 秒以内这样很好；可到了 4–5 秒的长尾，打电话的人会以为线断了，这是电话里最难受的沉默。
- 前端不能缩短长尾（那是 Codex 的工作），但可以如实说一句“还在想”：前提是当前阶段确实仍是 thinking，不编造进度，也不假装在说话。

## C. 构图与安静程度

### C1. 侧栏里面包贴在顶上，下面空着一大截 ★★

- `chat-1440`：面包、状态、电话占了侧栏上半部分（到 y≈490），下面 470px 是空墙。用户的视线在底部输入框，最新的消息也在底部。
- 布景的逻辑是“墙在上、地在下”，面包应该坐在地上。现在它坐在半空。另外，面包的眼睛会看向正在输入的框（`useLife` 的 `toward(field)`），它在顶上时只能“低头看”；坐到底部，它就是平视你写的字。

### C2. 空闲时的“停止”看起来像正在运行 ★

- `chat-1440` / `chat-390`：什么都没在进行，顶栏仍显示一个实心方块和深色的“停止”。它是可用的（Esc 永远可以停），但视觉上和“正在运行”时只差一个红底。
- 安静的页面不应该常亮一个“停止”。

### C3. 写字区的焦点环是冷蓝色 ★

- `chat-1440`：进入对话时输入框自动获得焦点，于是整个页面最显眼的边框是一圈蓝灰色的 `--focus` 光晕。它是页面上唯一的冷色块。
- 键盘焦点必须清楚，但写字区本身已经有光标；这里可以用和布景同色系的暖边，对比度仍然保持在 3:1 以上。按钮和链接的蓝色焦点环保留。

## D. 不改的东西（检查过，认为现在是对的）

- 照片“像素就绪再淡入”、失败不露孤立五官（`watchPlush` 的 wait/late/ready）：保留。
- 通话静帧到 3D 的原子切换、`useDecoded`、缩放重画：保留，不碰 `phone3d/*`。
- 44px 命中区、`aria-disabled` 而非 `disabled`、读屏文字、减少动态的全局规则：保留，新改动都放在这些规则之内。
- 首页电话压住面包右脚的构图：在电话不透明以后，这是有意的“前景道具”，保留。
- 窗光强度：截图里几乎看不见，没有读成“形状”，不动。

## 本轮要做的事（按价值）

1. A1 + A2：全站统一一套“暂时不能用”的电话调色：**不透明**，与通话页同一档 `saturate(.62) brightness(.97)`，状态切换时平滑过渡；去掉虚线框。
2. A4：手机顶栏在 ≤440px 时只留头像，保证“结束”完整可见。
3. B1：给会随状态换句的三处台词加上“余像”交叉淡化：旧句先退，新句后进；一闪而过的中间状态不会出现。当前句子立即渲染，不延迟真实状态。
4. A3：短标签按短语断行，不再孤字。
5. B2：去掉按能力状态加的外边距，改为标签不换行，英雄区不再跳。
6. A5：光池渐变改为“半径不超出盒子 + 缓动衰减”，去掉硬边和马赫带。
7. C1：侧栏里面包坐到地上（底部），地面光池随之下移。
8. B5：通话里真实等待超过约 2.6 秒后，字幕区底部安静地出现一句“还在想，再等我一下。”。
9. B3 + B4：朗读时小脸改为“看着自己那行字”的静止神态，“在想”的点改为只变亮度。
10. C2 + C3：空闲时“停止”降为浅墨描边；写字区焦点改为暖色边。
