# 面包 · 本轮细节实现说明

> Claude Opus 5.5，2026-11-05，基于 aa82f78。诊断见 [DIAGNOSIS.md](DIAGNOSIS.md)。
> **没有运行浏览器、类型检查、测试或构建。** 下面写的效果都是按代码推算的设计意图，需要在本机按第 3 节验收。

改动只在 `EDITABLE.json` 的范围内：`app/globals.css`、`components/hooks.ts`、`components/Companion.tsx`、`components/CallRoom.tsx`。没有新素材、新依赖、新字体，没有碰 `services/`、语音链路、`phone3d/*` 引擎和布局常量、提示词或配额。

---

## 1. 改了什么

### 1.1 不能打电话时，仍是那只红电话（DIAGNOSIS A1、A2）

- 新 token `--phone-quiet: saturate(0.62) brightness(0.97)`，就是通话页已经用了的那一档。现在首页、侧栏、空聊天、手机胶囊、SVG 回退和通话失败，全部用这一套调色。
- **不再半透明。** 去掉了所有 `opacity: 0.8 / 0.7`，也去掉了 `saturate(0.3)` 和 `saturate(0.2)`。
- 调色加在整张图上（首页是 `.phone-door__art`，其他地方是 `.phone-still[data-pose='down']`），静帧、SVG 和 3D 画布一起变，不会重复叠加。能力检查返回后，0.6s 平滑过渡，不再硬切。
- 侧栏不可用时不再画虚线框。手机胶囊不可用时改成“没抬起来的象牙键”：发丝边、无阴影、浅墨字。不再是虚线灰底。
- 不可用仍然靠文字说明，`aria-disabled`、提示文字和 `title` 都没变；地面的红光在 `down` 姿态下照旧熄灭。

### 1.2 手机顶栏不再裁掉“结束”（A4）

- `≤440px` 时，对话顶栏只保留头像，隐藏“面包”二字，和原来 `≤360px` 的做法一致。读屏名称和下方条里的“面包”都还在。
- `.topbar__controls` 设为 `flex: none`，“停止 / 结束”永远不会被压缩。
- 首页的完整字标不受影响。

### 1.3 台词换句是“交接”，不是“闪一下”（B1）

- 新 hook `useAfterimage(value, key)`，在 `hooks.ts`：词变了以后，在绘制前留下上一句的 `aria-hidden` 余像。旧句 0.26s 淡出，新句晚 0.1s、用 0.42s 淡入。只改透明度，不位移。
- **当前句子立即渲染**，不延迟、不改写真实状态。余像只是额外的装饰层。
- 只出现不到 260ms 的中间状态不会留下余像。比如发送时可能闪过一两帧的“我在。想说什么都行。”，它根本不会显现，而是由前一句继续淡出、直接交给“嗯，让我想想…”。
- 用在三处：
  - 侧栏字幕：`.companion__ghost` 与 `.companion__bubble` 重叠，原来的 `bubble-in-center` 位移动画已删除。
  - 手机条：`.perch__line` 改为 grid，`.perch__ghost` 与 `.perch__say` 同格。
  - 通话标题：`.callroom__phase-ghost` 放在 `<h2>` 外面，和它同格。标题元素、焦点、可访问名称都不变。
- 减少动态：全局规则把时长归零，余像立即消失，新句直接出现。

### 1.4 短标签按短语断行（A3）

- `Companion.tsx` 新增 `<Phrases text>`：按“，。、；：！？…”切成若干 inline-block，只在短语之间断行。超长短语仍会在内部换行，不会溢出。`textContent` 不变。
- 用在电话说明（`.phone-door__sub`）、侧栏字幕、胶囊提示上。侧栏说明再加 `text-wrap: balance`，结果是“现在打不了电话，/ 先打字吧”。
- 手机条的 `.perch__say` 是 `-webkit-box` 行截断，inline-block 子元素在不同引擎里的表现不确定，所以没有用。

### 1.5 首页不再因为能力检查而跳动（B2）

- 删除 `.entry__hero:has(.phone-door.is-blocked) { margin-bottom }`。
- 首页电话说明的第二行改为不换行，标签可以比电话宽：桌面居中，`≤900px` 向面包一侧延伸。这样标签永远是两行，检查前后英雄区一像素都不动。
- 大字号（l / xl）原有的固定预留保持不变。

### 1.6 光没有边（A5）

- 新 token `--pool-light`：`closest-side` 保证椭圆不超出自身盒子，再用 5 个色标做缓动衰减，取代线性渐变，消除边缘的马赫带。
- 用于 `.entry__hero::after`（首页地面光池）和 `.nook__table`（侧栏、结束页）。两处都去掉了会裁切渐变的 `border-radius: 50%`。
- `.cstage::before`（通话地面）用同样的写法，换成地面色。

### 1.7 侧栏里，面包坐在地上（C1）

- `.companion__figure { margin-top: auto }`：面包、状态和电话一起落到侧栏底部，和输入框、最新的消息在同一高度。上面只留墙和左上角的主光。
- 地面光池改为从侧栏底部向上 84px 处展开，用缓动衰减，跟着面包走。
- 窗口太矮时，`auto` 外边距归零，和以前一样滚动，不会裁切。
- 附带的效果：`useLife` 本来就会让面包看向正在输入的框，现在是平视你写的字，不再从顶上低头看。

### 1.8 通话里的长等待，如实说一句（B5，配合本轮“5 秒长尾”）

- `transcribing` 和 `thinking` 连续计为同一次等待。超过 `LONG_WAIT_MS = 2600` 后，字幕区**末尾**淡入一行小字：“还在想，再等我一下。”（`.callroom__wait`）。
- 只在阶段确实还是等待时显示，阶段一变就消失；不承诺时间，不说线路状态，不模拟说话。
- 放在字幕末尾，上方的字不会移动；按键贴底，也不会移动。用小号无衬线体，不用面包的字幕字体，因为它没有真的说出声。
- 不进入 `aria-live`，避免在面包开口的瞬间抢话。

### 1.9 不再循环抖动（B3、B4）

- 消息旁的小脸朗读时不再以 0.9s 节拍跳动（`bob` 已删除），改为瞳孔看向旁边那行字并停住：`.pm-look` 平移 `(32, 20)`，仍在玻璃之内。在 30px 的尺寸下这几乎只是“它在看那边”。
- “在想”三个点只变亮度、不再上下跳，节奏放慢到 1.8s。

### 1.10 更安静的顶栏和写字区（C2、C3）

- 空闲时的“停止”是浅墨描边方块；面包真的在忙时变成实心、暖红底（`.is-hot`，原样保留）。按钮始终可用，Esc 照旧。
- 写字区（对话输入框、首页便签）的焦点从蓝色光晕改为面包皮色边（`--write-edge`，对墙面约 3.4:1）加一圈很淡的灯光（`--write-halo`）。其余按钮和链接的蓝色焦点环不变。

## 2. 没有动、并且刻意保留的

- 照片“像素就绪才显示”和失败时不露孤立五官：`watchPlush`、`data-plush` 和面部 mask 全部原样。
- 通话静帧与 3D 的原子切换、`useDecoded`、缩放重画、慢静帧不阻塞收音：没有碰 `CallStage.tsx`、`Phone3D.tsx`、`phone3d/*`。
- 44px 命中区、`aria-disabled`、读屏文字、键盘焦点、减少动态、特大字、320px：新规则都在这些规则之内。余像全部 `aria-hidden`、`pointer-events: none`。
- 所有点击、输入、收音、挂断路径都没有新的等待。新句子的 0.1s 起始延迟只影响文字的透明度，不影响任何交互，DOM 里的文字是立即更新的。

### 可能影响现有测试的地方（请 Codex 留意）

- 选择器没有改名。`.companion__bubble`、`.perch__say`、`.callroom__phase`、`.phone-door__sub` 的文字内容都和以前一样。
- **余像存在的约 0.42s 内**，`.perch__line` 和 `.callroom__status` 的 `textContent` 会多出上一句。Playwright 的 `toHaveText` 会自动重试，所以通过；但如果某个单元测试在重新渲染后立刻断言整段 `textContent`，可能需要改成断言 `.perch__say` 或可访问名称。余像不在 `.companion__bubble` 和 `<h2>` 之内。
- 断言 `.call-pill.is-blocked` 为虚线边，或断言电话 `opacity: 0.8` 的视觉测试，需要更新预期。
- 首页不可用时，英雄区不再有额外的 `margin-bottom`。如果有测试量过这个距离，预期需要更新。
- 慢回复夹具超过 2.6s 时，字幕区会多一个 `.callroom__wait`。它不带 `cap` 类，不会影响 `.cap` 的计数。
