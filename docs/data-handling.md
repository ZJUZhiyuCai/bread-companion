# 数据处理与边界

文字输入、完整来源、聊天和录音默认只在当前页面内存中。刷新不恢复这些内容。结束先封闭运行、停止所有媒体，再清掉原始对话与来源；仅保留当前已展示且有效的卡片及其所需摘录的最小只读快照（可以是未保存草稿），供本人在结束页主动保存/导出；刷新后这份未保存快照也会消失。结束不会确认或自动保存卡片。

本地运行时真实文本经本机 Magpie 路由；在线体验经本站 Worker 直接连接同一上游：文字与电话聊天、整理、复盘与练习到万界方舟的 DeepSeek 服务。请求包含当前问题、受限的相关对话、本次明确交流偏好及最多六段来源；完整长材料留在页面，客户端发送前就限制整包大小。MiniMax 接收需要转写的录音片段和需要合成的回复文本。文字聊天中，单段录音需本人完成、修改转写后发送，回复只在本人点击播放时合成。

默认音色的固定开场使用预生成、本机提供的合成音频，不包含用户内容，也不为每次拨号重新调用供应商。其他音色或开场文件缺失时使用配置的 TTS；不会将普通对话放进开场缓存。明确、无歧义的道别也可由本机规则直接回应，无需模型往返。

点击电话按钮即选择停顿后自动转写、发送和播报；详细机制可从 AI 标记打开“关于”查看。浏览器本地 AudioWorklet 采集 PCM，用音量与停顿切出最多 55 秒的片段，再转成 16 kHz 单声道 WAV 上传，不分析用户的情绪或身份。面包思考、转写和说话时也在本机检测开口；检测到本人说话会中止旧回合，保留开头继续听，停顿后再上传新片段。若前半句尚未完成转写，会在内存中拼接前后两段后重新转写，合计仍限制55秒。播放器参考 PCM 与回声判定仅留在本机内存；不是持续把整段通话上传。静音停止提交并清空当前未提交片段；暂停、切后台、挂断、结束会关闭音轨和 AudioContext。持续安静一分钟自动暂停。挂断保留当前文字聊天，结束仍按下述规则清除完整聊天。模型、语音服务及 Magpie 可能有各自的数据保留或诊断记录；本轮没有逐项审计其实际政策，不承诺“完全无痕”。页面在首次发送前可查看处理方说明。

应用没有账号和服务端内容数据库。本地模式的重复请求防护只临时保留请求 ID（最多 1,024 条、10 分钟），进程重启会清空。在线模式会自动设置有效期 12 小时的 HttpOnly / Secure / SameSite=Strict 匿名 cookie；不使用指纹或原始 IP 做应用配额键。D1 仅保存加密散列请求标识、带密钥的匿名访客标识、能力通道与创建/租约/到期时间，用于跨实例配额和去重，不保存正文、录音、回复或材料。记录到期为创建后 24 小时，下一次准入时删除到期记录；低流量下物理保留可长于 24 小时。租约最长 120 秒，取消和正常完成会尽快释放活跃计数。共享数据库不可用时拒绝新的付费调用。业务错误只返回安全错误码；诊断仅含阶段、校验字段路径/错误码、HTTP 状态和耗时，不记录正文、音频、姓名、密钥或供应商原始错误内容。开发服务器自身保留本地进程日志；线上托管平台可能保留请求与运行诊断元数据，平台保留政策不等于本应用的正文不落库策略。

用户直接提交、粘贴或修正的原话，表示本人愿意把这段文字用于当前会话；不再要求重复确认来源类别，也不代表外部事实已核验。恢复旧卡片时仅带入此前主动保存的有效原文摘录。

在保存预览点击“就留下这些”会把认可当前表述和本地保存合为一次明确动作；主动导出同样只包含当前展示的有效版本。agent 不能替用户确认、保存或导出。IndexedDB 仅保存所选卡片版本、关联结论、选定摘录以及用户确认的材料。没有完整聊天、全部 JD、原始音频。当前版本练习内容纳入已确认复盘卡，不单独保存完整练习聊天。

IndexedDB 是当前浏览器的同源本地存储，不是云备份、身份隔离或加密承诺。共用此浏览器的人可能看到已保存卡片；浏览器或本人也可能清理存储。JSON 导出可由本人保管，导入严格校验版本、关联与大小。损坏存档不会悄悄导入。

删除按案例清除本机存档及相关内存快照，同时使未完成保存失效，不能从已删除的结束快照再次导出。删除不会清理本人已下载的文件，也不能撤回供应商已经处理或保留的数据。

停止/结束会取消本机请求与媒体并丢弃迟到结果。AbortSignal 继续传到供应商 fetch；这不证明远端计算或费用一定立即停止。网络或超时错误默认不自动重试，手动重试可能带来额外调用。

本地地址和在线域名属于不同 origin，存档不会自动迁移。可主动导出/导入已确认卡片。自托管字体和固定欢迎音频不携带对话内容。公开体验的全站滚动 24 小时限额为 1,200 次已准入 API 请求（转写、模型、合成分别计数），不是无限使用承诺；每访客和各能力还有较小上限，见 [部署指南](deployment.md)。
