# 数据处理与边界

文字输入、完整来源、聊天和录音默认只在当前页面内存中。刷新不恢复这些内容。结束先封闭运行、停止所有媒体，再清掉原始对话与来源；仅保留当前已确认且未失效卡片的最小只读快照，供本人主动保存/导出。

真实文本会经本机 Magpie 路由到万界方舟的 DeepSeek 服务。请求包含当前问题、受限的相关对话及最多六段来源。MiniMax 接收本人主动完成的录音片段，或本人点击播放的已展示回复。模型、语音服务及 Magpie 可能有各自的数据保留或诊断记录；本轮没有逐项审计其实际政策，不承诺“完全无痕”。页面在首次发送前可查看处理方说明。

应用没有账号和服务端内容数据库。业务错误只返回安全错误码；诊断仅含阶段、校验字段路径/错误码、HTTP 状态和耗时，不记录正文、音频、姓名、密钥或供应商原始错误内容。开发服务器自身保留本地进程日志。

“确认这一版”只代表本人认可表述或材料归属；保存还需要一次明确的保存预览操作。IndexedDB 仅保存所选卡片版本、关联结论、选定摘录以及用户确认的材料。没有完整聊天、全部 JD、原始音频。当前版本练习内容纳入已确认复盘卡，不单独保存完整练习聊天。

IndexedDB 是当前浏览器的同源本地存储，不是云备份、身份隔离或加密承诺。共用此浏览器的人可能看到已保存卡片；浏览器或本人也可能清理存储。JSON 导出可由本人保管，导入严格校验版本、关联与大小。损坏存档不会悄悄导入。

删除按案例清除本机存档及相关内存快照，同时使未完成保存失效，不能从已删除的结束快照再次导出。删除不会清理本人已下载的文件，也不能撤回供应商已经处理或保留的数据。

停止/结束会取消本机请求与媒体并丢弃迟到结果。AbortSignal 继续传到供应商 fetch；这不证明远端计算或费用一定立即停止。网络或超时错误默认不自动重试，手动重试可能带来额外调用。
