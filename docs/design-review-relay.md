# 评审期第二遍打磨：把灯放近一点

基线：`058ad153e27bd6470a7e5ef4cab778a93d659a6d`。
本轮是视觉与必要界面反馈的第二遍打磨，没有修改 `services/`、`server/`、`domain/`、`prompts/`、`app/api/`、数据库、密钥或部署配置。Codex 刚接上的连接原地恢复、草稿保留、44px 触摸区域、3D/静态降级和减少动态偏好全部保留。

## 判断

上一轮已经把房间变亮、把按钮变轻。这一轮不再换风格，而是解决“亮而无重、轻而无序”的几处：

- 页面可以更暖一点，但按钮和纸面必须有明确的前后关系；暖色集中在灯光和纸，不用金色描边填补空白。
- 首页第一屏的动作要有顺序：先停留，再听，再写，电话始终在面包手边。视觉不能把四个入口做成同样重的卡片。
- 聊天页在窄屏上曾把面包的第一句话截断；这条小缝比任何装饰都更影响“被接住”的感觉。
- 通话页是停留时间最长的界面：上方状态、中央画面、下方操作要像一间房，而不是一堆居中的组件。
- 连接失败、通话失败和结束是评审最容易撞上的边缘状态；它们应该有清楚的下一步，而不是只给一句红字。

## 这轮实际改了

### 房间和纸

- 页面底色 `#faf7f0 → #f9f4eb`，更高密度的灯池和底部桌光；主要纸张仍是 `#fffdf9`。正文墨色 `#352f28`，弱文字 `#6d6458`，在底色上约 `5.3:1`。
- 首页新增一层很轻的墙面光晕和桌沿暖影；标题上方加入一条 34px 的短线，作为页面的“开头”。
- 通话页顶栏与房间同色，去掉一条把画面切断的横线；给中央画面加更宽的低光，给三枚按键加非常浅的桌面反光。
- 结束页加入同一笔开头短线、更低的夜灯和底部桌光；回执纸在深色主题改为暖暗纸而不是冷蓝灰。

### 字和层级

- 首页标题放大到 `clamp(2.1rem, 4.35vw, 3.08rem)`，字距收紧，行高更紧；正文稍宽、行高保持舒展。这个标题现在像一句写在纸上的话，而不是网页大标题。
- 通话状态标题稍大；实时状态改为居中的小胶囊，时长用等宽数字，减少顶部的零散文本。
- 结束页标题使用与首页相同的字号/行高语法；卡片标题和正文保持现有层级。
- 微小标签（状态、辅助说明、时间）统一更紧的字距和较稳的行高。

### 操作

- 首页“先听”从一张独立卡片改成一条安静的行：上下两条发丝线、左侧耳机、右侧播放键。这样便笺重新成为第一屏唯一的“纸”，层级更清楚。
- 便笺未输入时的主键从透明 ghost 改为暖纸键；输入后才变为墨键。它仍然 44px，仍然只承担一个动作。
- 面包的角落电话（聊天窄屏）缩为更小的电话图标 + “打电话”胶囊，释放文本宽度；面包的第一句话现在完整显示，不再以省略号截断。
- 通话主键稍大，中心键与两侧键保持稳定的位置关系；挂断保留浅豆沙底、红图标，并补上红色标签，便于在浅色背景上辨认“停下”的方向。
- 错误状态加入警告图标，消息改为一条可扫读的浅色提示；重试仍在中央主键。
- 连接恢复提示移到顶栏下方，作为服务状态条：圆点、原提示和“重新连接”。检查中使用 `aria-busy`、转圈图标和“连接中”，不遮住便笺和发送区。草稿仍原样保留。
- 所有新增/改动的触控目标保持 44px；320px 下通话控制不再超出视口。

### 连接、动效和无障碍

- 没有新增循环动画。保留的呼吸光只在面包正在说时运行；新连接圆点复用原有的极轻呼吸；`prefers-reduced-motion` 下全部静止。
- 电话模型、静态海报和 SVG 的切换分层未动。
- 电话按钮加了明确的 `aria-label="给面包打个电话"`，避免旋号盘数字被读进按钮名称；AI 状态的可访问名称仍完整。
- 键盘焦点在电话铭牌、写话区、通话键和连接按钮上都有可见外框；正文对比度在 axe 的浅色/深色检查中通过。
