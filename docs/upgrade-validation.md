- 音频/VAD 继续逐帧执行；装饰性音量 UI 更新节流为 80 ms。修复屏幕阅读器在回答结束后仍保留“在想”的旧状态。

## 文字延迟实测

测量口径：同一台机器、本机生产服务的 HTTP 请求发出到完整响应到达；同一组 8 条虚构情境，先测旧服务，再测新服务。不是随机交错实验，也不是供应商 SLA。旧服务为提交 `0accbde` 的 v11 Gemini 路由，新服务为本轮 v12 DeepSeek 路由，均非流式呈现。

| 版本 | 8 条成功数 | 中位数 | 范围 |
| --- | ---: | ---: | ---: |
| 原文字 Gemini 3.8 Flash | 8/8 | 5.248 s | 4.124–6.982 s |
| 本轮文字 DeepSeek Flash | 8/8 | 1.145 s | 0.960–1.483 s |

这组样本中中位耗时降低 **78.2%**。16 条完整情境均返回 200，出现一次 **5.980 s** 慢回复；不能把约 1 秒说成保证或忽略长尾。另做 6 条未用于调提示词的新情境，全数返回 200，包括原因不确定、同伴比较、普通生活话题、早先“不追问”偏好与后续允许提问。

有意保留语气评审结果：新模型的速度适合此链路，具体回应和身份诚实性可用，但仍会偶尔主动给生活建议、过度复述、补写用户没有说明的轻重关系或给出偏生硬的拒绝。本轮约束降低了部分问题，没有据此宣称“情商已认证”。快速模型与对话质感之间仍需目标用户实测；不会在失败时偷偷换供应商。

原始结果保留在本机 `.local/text-before-upgrade.json`、`text-after-upgrade-initial.json`、`text-after-upgrade.json`、`upgrade-live-holdout.json`，输入均为合成情境。复测命令：

```sh
node scripts/evaluate-companion.mjs --app http://127.0.0.1:3210 --out .local/text-after-upgrade.json
node scripts/evaluate-upgrade.mjs
```

以上命令会调用已配置的真实模型，不在 CI 中运行。
