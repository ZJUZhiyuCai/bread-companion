# 面包 · 动效与延迟：实现说明

> Claude Opus 5.5，2026-11-04，基线 3e4ad81。诊断见 `DIAGNOSIS.md`（D1–D19）。
> **没有运行浏览器、构建、类型检查或测试。** 下文所有效果都是设计意图，“验收”一节列出需要 Codex 在本机确认的项目。

## 1. 进场：面包先到，并且整只到达（D1–D3）

- **预加载面包。** `layout.tsx` 加了 `bread-plush.webp`（`fetchPriority="high"`，放在最前）和小花 `felt-flower.svg`。电话静帧的预加载保留。
- **五官跟着身体出现。** 腮红、小花、眼睛、睫毛、缝线嘴放进 `<g class="p-face">`，以照片自身的 alpha 作蒙版（复用已有的 `-body` 遮罩）。这一步不依赖 JS：水合之前，照片没到，五官就画不出来，所以不会再有浮在墙上的眼睛。`BreadMark` 同理（`pm-face`）。
- **整只淡入。** 第一个面包挂载时，`watchPlush()` 在 `<html>` 上写 `data-plush`：
  - 水合时照片已经下载完（Resource Timing 能查到，或 `img.complete`）→ 直接 `ready`，**不会把已经在屏幕上的面包再藏起来**。
  - 还在路上 → `wait`：页面上所有面包（含顶栏头像）先藏住。解码完成后变成 `ready`，整只 0.7 秒淡入，包括身体、五官、小花和影子。
  - 超过 2.4 秒仍未到达 → `late`：先显示已有的部分，五官继续等身体。
  - `ready` 之后五官上的蒙版用 CSS 去掉（`mask: none`），之后每次重绘不再多走一遍蒙版。
- **“我是面包”等面包到了再说。** `wait` 期间 `.hello-bubble` 的动画处于暂停状态，0.4 秒的延迟从面包到达时才开始计。
- 任何按钮、输入框、电话的可用时间都不受影响。藏起来的只有面包这张图。

## 2. 动作放到合成层，只保留一个常驻循环（D4–D9、D11）

**结构。** `PlushSvg` 现在渲染 `<span class="plush-motion" data-buddy=状态>` 包住原来的 `<svg class="plush">`。各类动作的归属如下：

| 动作 | 以前 | 现在 |
|---|---|---|
| 呼吸 | SVG 内 `.p-breathe`，每帧重画 | 外壳上的独立属性 `scale`，合成层，静止时不重画 |
| 用户说话时点头 `nod` | 1.6s 无限循环，按节拍 | **删除**。改由真实电平带动的前倾（下一节）和一轮结束时的一次点头表达 |
| 思考 `ponder` | 3.6s 无限摇摆，进入和离开时各跳一次约 2° | **改为保持的姿势**（头歪 2°，0.9s 缓入），加上眼睛在两个点之间停留（原有的 `useLife`）和思考气泡 |
| 说话时一句一抬 | `.p-pose` 的 SVG transform | 外壳上的 `translate`/`rotate` 过渡（`data-phrase`、`--tilt` 写在外壳上） |
| 电平前倾 | SVG 内 translate 加瞳孔缩放，跟着电平连续重画 | 只在通话舞台 `.cstage__plush` 上用 `translate`，合成层；瞳孔不再跟电平 |
| 思考气泡、月亮、汗滴、徽章 | 与面包同一张 SVG | 外壳内另一张小 SVG `.plush-extras`，冒泡时只重画几个小圆 |
| 说话时缝线 | 60fps 改 path | 最多每 32ms 画一次（`SEAM_FRAME_MS`）；减少动态时照旧保持静止的微张 |

- 夜晚的慢呼吸（7s）保留，因为晚安页的面包总是新挂载的。暂停/静音不再改呼吸时长：动画中途改时长会让呼吸跳相位。
- `PlushSvg` 和 `PhoneFigure` 用了 `memo`。通话中电平和计时器的更新不再重渲染面包与矢量电话；`--lvl` 只在 `.cstage` 上设置一次，由 CSS 继承。
- **两处模糊。** 顶栏的 `backdrop-filter` 去掉，视觉上没有差别（下面只有平滑的墙）。打开对话框时，背后的呼吸、思考气泡、侧栏状态点、通话直播点和 `.session::before` 暂停（`body:has(dialog[open])`），模糊背景不再每帧重算。“关于”里的面包照常呼吸。
- 通话的绿点改为伪元素的 `scale` + `opacity`，不再动画 `box-shadow`。

## 3. 通话中的“等”（D12–D15、D10）

- **说完时光不掉。** 思考/转写的底光就是安静收听时的亮度（0.62），不再跳到 0.46。呼吸放在第二层光 `.cstage__light::after` 上：动画一直在跑，深度由注册的自定义属性 `--breath` 控制，进入思考时 0.9 秒长出来，离开时从当前所在的那一口气退回去。**动画永远不会被剪断，所以不会跳。**（不支持 `@property` 的浏览器里，呼吸会在相位切换时直接出现或消失，其余不变。）
- **“嗯，收到了”。** 相位从 `listening` 变为 `transcribing` 或 `thinking` 时，`.cstage__plush` 以脚为轴点一次头（0.76s，`ack`）。只在这一真实变化时发生一次，不暗示回复已经到了。
- **灯亮起来。** 进入通话时，墙上的光用 1.2 秒从 0 升到当前相位应有的亮度（`light-up`，只填充 backwards，之后完全交给相位规则）。按键、标题与收音不等它。
- **相位标题在原地换行。** `<h2>` 不变（焦点与读屏不受影响），里面的 `<span key={标题}>` 轻轻上浮 4px 淡入。
- **字幕像电影字幕一样换行。** 字幕以开头 6 个字作 key：同一句在增长时位置不变；换了一句才作为新字幕上浮出现。被打断的那句改为 0.35 秒退淡（之前的过渡写在了不会变化的父元素上）。
- **通话键只换图标。** 按钮本身从不重建，也不延迟可按；图标在原位 0.24 秒淡入、轻微放大。静音键在“静音/已静音”之间切换时也一样。
- **打开文字记录。** 舞台宽度不再做过渡（之前会逐帧重建 3D 缓冲），改为切到近景，记录面板上浮出现。

## 4. 文字对话（D16–D18）

- **“在想”不闪。** 占位行里的小头像立即出现，“在想…”这几个字等 0.28 秒再淡入。0.25 秒内回来的回复会直接替换它，不会闪一下。角落/顶条上的状态与读屏播报照旧即时。
- **头像不眨。** 回复行整行不再淡入，头像在原位保持，只有文字出现。
- **面包的话是写出来的。** 回复正文用一条从上往下移动的柔边蒙版显现，0.7 秒，ease-out，第一行约在 0.1 秒内就可读。蒙版只存在于动画期间。欢迎明信片带阴影，改为整张落下（`rise`），避免阴影被蒙版切掉后又突然出现。
- **你的便签从你这边递过来：** 从右下角上浮 12px，缩放 0.985 → 1。
- **朗读高亮淡入淡出。** 面包的每句话平时都带一条透明的荧光笔线，朗读时颜色 0.45 秒渐显，停止时渐隐。强制配色模式下只给正在朗读的那句加线。

## 5. 同一个面包在页面之间移动（D19）

- **`morph(update, { keyboard })`**（`hooks.ts`）调用 `document.startViewTransition` 加 `flushSync`。有三个共享名字：`bread`（面包）、`bread-phone`（电话）、`bread-name`（顶栏名字）。
  - 首页 → 对话：大面包滑进左侧角落（手机上是顶条里 48px 的小面包），电话滑到它的位置，名字从首页左上角移到顶栏。其他部分 0.34 秒交叉淡化，共享元素 0.56 秒。
  - 对话 → 晚安（文字对话中点“结束”，且没有进行中的事情）：面包走到灯下。
  - 晚安 → 首页 / 再说一会儿：反向。
- **故意不用的地方。** 以下步骤**直接切换**：打电话（`call`）、挂断、通话中点“结束”、“先听一小段”（会播放声音；Safari 的播放解锁可能要求在点击内完成）、有进行中的生成/朗读/录音时点“结束”。
- **手机键盘。** 进入对话会自动聚焦输入框；在触屏上，聚焦必须发生在点击之内，键盘才会弹出。所以带 `keyboard: true` 的步骤在 `(pointer: coarse)` 上不做过渡。
- **过渡期间可以操作。** `::view-transition { pointer-events: none }`，新页面从第一帧起就能点。
- **降级。** 不支持、减少动态或页面隐藏时直接执行；共享名字重复导致过渡被跳过时，更新照常完成且不报错；更新本身出错时用 `reportError` 上报，不会被吞掉。
- **进入对话的招呼。** 原来的 `wave` 是两次 64 单位的弹跳，改为等 0.45 秒（面包落座后）做一次下沉、抬起、回落（`hello`，30 单位），地上的影子跟着收紧一点。

## 保留不变的约束

- 电话的缩放即重画、晚到首帧直接采用当前姿势、静帧原子切换，以及 3D 与静帧的降级顺序：引擎、`Phone3D.tsx`、静帧逻辑**都没有改**。`CallStage` 里只是把面包从嵌套 SVG 拿出来，电话的叠放顺序（矢量 → 静帧 z1/z2 → 3D z3）不变。
- 焦点：通话标题 `<h2>` 和按键 `<button>` 都不会被重建；`aria-live`、`aria-disabled`、44px 触控区不变。
- 减少动态：全局规则仍让所有动画瞬间结束。思考时的光在这种模式下改为静态的 0.76，作为与收听的相位差异；View Transition 不启动。
- WebGL / 静帧降级：未触碰。

## 需要本机验收

**进场**

1. 清缓存、慢 3G：首页先是墙和文字，然后面包整只淡入（不能出现单独的眼睛、腮红、小花或影子），然后才是“我是面包”。电话可以与面包同时或稍后出现，但不应明显早于面包。
2. 有缓存、普通网络：首页面包**不闪、不重新淡入**（应直接是 `ready`）。请确认 `performance.getEntriesByName` 在你们的部署（CDN、`next/image`、`basePath`）下能匹配到 `/companion/bread-plush.webp` 的绝对 URL；匹配不到也只是退回 `img.complete` 判断。
3. 禁用 JS：面包出现时五官同时出现。小花若有花瓣超出身体轮廓，会被裁掉，只在这种情况下发生。
4. 首屏 LCP 元素和瀑布图：面包照片应与字体、电话静帧同在第一批请求里。

**合成与帧率**

5. 首页静置 10 秒的 Performance 记录：除每 5–9 秒一次 0.9 秒的眼睛反光外，不应再有每帧的 Paint。呼吸应只出现在 Compositor 轨道。
6. 通话收听期间（说话）：面包不应每帧 Paint；墙上的光和面包的前倾随电平变化。React Profiler 中 `PlushSvg`、`PhoneFigure` 不应随电平提交。
7. 面包说话时：缝线约 30fps，与声音的“节奏感”仍然成立；一句一抬的动作是否平滑。
8. 打开“关于”或手机托盘：背后的面包停止呼吸，模糊背景不再每帧重算；关闭后继续。
9. 打开/关闭通话文字记录：没有逐帧 resize；3D 电话一次重画就位。

**通话**

10. 每一轮“说完”：光不往下掉；面包点一次头；标题淡换成“嗯，让我想想”；随后光开始缓慢呼吸。开口回复时，呼吸退回去，没有跳变。
11. 打断（说话中开口）：被打断的那句 0.35 秒退淡；光迅速亮起；没有残留的呼吸。
12. 主键在 说完了 → 插话 → 说完了 之间切换：键的位置、大小、焦点不变，只有图标翻转；用键盘 Tab 停在主键上切换相位时焦点不丢。
13. 字幕：流式增长的一句不应反复重新上浮；换成下一句时才上浮一次。**如果后端在同一句里改写开头几个字，会多出一次上浮**，请看真实链路。
14. 接通时灯从暗到亮约 1.2 秒，按键从第一帧就能按。
15. 静帧 → 3D 交接、晚到首帧采用当前姿势、缩放重画：回归上一轮的五条测试。

**页面之间（Chrome / Edge / Safari 18+ / Firefox 144+）**

16. 桌面首页 → “进去慢慢写”：面包和电话滑进左侧角落，名字移到顶栏；输入框获得焦点；过渡期间立即打字、点击都有效。
17. 手机首页 → “进去慢慢写”：**不做过渡**，键盘照常弹出（iOS Safari 必看）。
18. 首页 → 打电话、“先听一小段”：直接切换，麦克风请求和开场声音没有任何延后。
19. 文字对话空闲时 → 结束：面包走到晚安的灯下；有回复在生成或朗读时点结束：直接停止、直接切换。
20. 晚安 → 回到开始 / 再说一会儿：反向移动。
21. Playwright：过渡期间 `elementFromPoint` 和点击应落在真实 DOM 上（`pointer-events: none`）；截图类用例如在过渡中途截图，需要等 `document.getAnimations()` 结束，或用 `prefers-reduced-motion` 跑。

**减少动态 / 强制配色**

22. 减少动态：没有页面过渡；思考时光是静态的、比收听亮一些；进入对话时面包不弹跳。
23. Windows 高对比度：面包回复下没有常驻的粗线；只有正在朗读的那句有标记。

## 风险与回退

- **`.plush-motion` 外壳。** 如果有测试或选择器依赖 `.plush` 的父元素是 `.plush-wrap`，或者依赖 `svg.plush[data-phrase]`，需要改成外壳（`data-phrase` 现在在 `.plush-motion` 上）。`.p-breathe` 这一组仍在 SVG 里，只是不再承载动画。
- **`watchPlush` 的 `wait`。** 这是唯一可能“藏东西”的逻辑，而且只藏面包本身。如果实测出现已经可见的面包被重新淡入，最小回退是删掉 `html[data-plush='wait'] :is(.plush-motion, .bread-mark)` 这一条 CSS。蒙版部分可以单独保留。
- **View Transitions。** 回退方法是把 `morph(fn)` 改回直接 `fn()`。CSS 的 `view-transition-name` 在没有过渡时不产生任何效果。
- **`ink-in` 蒙版动画** 每次新回复都会重绘 0.7 秒正文。若低端机上卡，可改为 `rise`。
- 不在本轮范围、需要 Codex 测量后决定的（见 DIAGNOSIS §6）：`vm.call.level` 引发的整树渲染频率、带 `mask-image` 的对话滚动容器、接通后 3D 首次初始化的长任务。
