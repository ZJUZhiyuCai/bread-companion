# 评审体验迭代计划

目标：从邮件里的入口打开面包，能顺利倾诉、复盘、修改、保存；电话可以接通、打断、挂断。以实际流程是否走通来决定发布，不以新增功能数量衡量进度。

## 本轮：先把已完成的体验交到线上

1. 发布 `881a104` 的浅色设计，保留毛绒面包、3D 电话与既有静态降级。手机真实触摸目标补到 44px。
2. 修复首次服务检查失败后无法恢复的问题：原地重新连接，网络恢复或回到页面时可再次检查；保留输入与已有对话。检查有 8 秒截止时间，同一时刻仅一个请求，离开后取消，迟到结果不得覆盖新状态。该流程不自动重发文字、不打开麦克风、不调用付费模型。
3. 验证从首页到复盘、纠正、重做、练习、保存和结束；电话另测空转写、拒绝麦克风、切后台、打断、重试与挂断。
4. 在独立版本目录构建，核对来源哈希。切换前检查候选服务，保留上一版本与上一版带哈希的前端静态资源；异常回退。数据库与模型配置独立于源码版本。
5. 更新 README 图片与实测记录，使仓库、提交材料和在线界面一致。

## 发布门槛

- 类型、单元/集成、模型资产、生产构建及完整浏览器流程通过；CI 另在 Linux Chromium 上复核。
- 320px 手机布局、大字号、浅色与深色界面可操作，输入不丢失。
- 公网验证匿名进入、真实转写 → 模型 → 播放、重复请求拒绝及跨域拒绝。只使用少量虚构文字和合成音频。
- 已打开的旧页面在发布后仍能获取它引用的静态脚本。
- 记录页面、转写、模型、合成各段耗时及失败，不把 HTTP 成功解释为用户体验合格。

## 后续按证据排序

| 优先级 | 要解决的问题 | 进入实现的条件 / 验收 |
| --- | --- | --- |
| P0 | 进入失败、对话丢失、麦克风无法停止、卡片版本错乱 | 有复现即优先修；加入对应回归，失败版本不发布 |
| P1 | 电话等待时间与跨境长尾 | 持续区分 ASR、文本、TTS 耗时；流式链路需一起验证取消、开口打断、空结果和回声，不能直接替换已验证链路 |
| P1 | 手机真机体验 | 鸿蒙系统浏览器与微信分别记录；桌面模拟和网络探针不能代替真机麦克风、外放与蓝牙 |
| P2 | 回复贴合场景 | 保留同理心约束，观察纠正后的实际多轮回应；不以固定安慰句或自动“情商分”判定质量 |
| P2 | 视觉细节 | 优先信息层级、按钮反馈、窄屏与键盘；保持安静的场景与已批准形象 |

评审期采取小批次发布。监测不读取私人正文，不自动发送邮件，也不为压缩模型延迟重复发起付费竞速请求。

## 2026-11-01 本轮验证

- 216 项单元/集成测试、50 条生产构建浏览器流程通过；类型与 3D 模型检查通过。
- 新增回归覆盖首次服务检查失败、手动/网络恢复、输入保留、并发去重、8 秒超时、卸载取消及迟到响应。
- 构建不再因 SQLite 运行时目录解析追踪整项目；私有路径、符号链接与 SQLite 并发测试保持通过。
- 本机首次以 CI 默认浏览器启动时缺少对应 Chromium 二进制，测试未能运行；随后使用已安装 Chrome 和仓库的生产测试配置执行完整 50 条流程。CI 在 Linux 安装固定版 Chromium 后独立验证。
- 发布前真实公网合成样本：ASR 1.413 秒、DeepSeek 5.839 秒、TTS 1.173 秒，三段均 HTTP 200；无 cookie / 跨域请求拒绝，重复请求 409。此为一次 HTTP 链路，不是用户声学等待时间。
- 同次桌面浏览器冷访问：HTML 首字节约 0.631 秒、DOMContentLoaded 1.105 秒、load 1.442 秒；仅代表该设备与网络。真实鸿蒙/微信、蓝牙与外放仍需分别验收。
