# 陪伴文本模型：本机评估与选择

2026-10-31。倾听与通话选用 Magpie 中的 `mfapi/gemini-3.8-flash`，整理、复盘和练习保留 `wanjie/deepseek-v4.1-flash-1017`。MiniMax 继续负责转写和 `Chinese (Mandarin)_Warm_Bestie` 播报。当前 Magpie 列表没有可调用的豆包，因此没有声称比较过豆包，也没有新建付费账号。

这是合成情境的工程评估，由 Codex 检查回复；没有真人受试者、盲评或统计性情商评分。模型名来自本机路由，不能据此独立证明服务商底层部署的版本。比较的是当前接入组合的实际表现。

## 怎么测

16 个固定情境包括：拒信失落、讨厌安慰套话、拒绝问题和建议、分享小好事、羞耻和比较、未知拒因、修正误读、排他依赖、AI 身份、只要一件小行动、轻幽默、告别、前轮不追问偏好、原因不明、短电话回复、要求虚构优越性。部分样本带固定历史，不能称为真实多轮评估。

先测原提示词，再针对问题调整提示词。v7 的 DeepSeek、Gemini 和 MiniMax 使用相同情境、同版风格提示及 4,096 输出 token 上限。DeepSeek 经应用校验与至多一次修复；另外两者直接经 Magpie 请求，因此耗时和 JSON 成功率不是严格同条件排名。GLM 的探测早于 v7，单独记录，不与后面的结果作同条件优劣结论。

| 接入 | 观察到的表现 | 代价/问题 |
| --- | --- | --- |
| DeepSeek V4.1 Flash | 16 个 v7 应用请求返回有效结果；文字阶段中位 1.35 秒，原有证据复盘链路可用 | 原提示词常以追问、二选一结束；调整后仍有未提供细节、指正式口吻和多余追问。部分安慰偏生硬 |
| Gemini 3.8 Flash | 16 个 v7 探测返回 JSON；较少强迫继续回答，对话转向、纠正和普通小事较自然；中位 5.84 秒 | 有一条无依据夸赞/站队，随后增加明确约束和程序拦截；也曾编造记忆和照片场景，需要后续修正 |
| MiniMax M3.1 Flash 文本 | 16 个 v7 探测返回 JSON；中位 4.44 秒 | 有样本把“不想回答问题”误接成“我不回答问题”；请求一件事时给出多个任务，仍有套话和多余追问 |
| GLM 5.3 Flash（v5） | 16 个探测中 15 个 HTTP 200、1 个超时 | 只有 8 个结构正确的 JSON；本次接入与提示组合不够稳定，不能据此断言模型整体情商差 |

时间都是单轮样本，不是 SLA；HTTP 200 和合法 JSON 也不代表情感表达一定合适。

## 复测与实际修正

选择 Gemini 后，在应用链路用 v8 跑了 8 个新情境和两段真实连续三轮对话，共 14 轮，均通过接口与结构校验。多轮中会接纳“其实更怕房租”的新信息，也会随用户从面试转到猫咪贴纸，未继续强推复盘。

这组新情境仍发现：没有历史时说成“现在想不起来”，从火锅照片编出场景，从单个顺利片段肯定整体能力。v9 补充了记忆、感知和事实边界；随后 6 个定向及新情境复测均返回有效结果，对“听出我在哭吗”明确说只能看转写文字。但对“后台是否记录”仍给出了过度宽泛的遗忘描述。

v10 加入准确的数据处理事实，两个隐私回归样本均明确区分本地聊天与服务商可能保留的记录。最终版本还经过真实五阶段流程与语音链路，见 [验收记录](acceptance.md)。这些样本参与了迭代，不能把它们当作未见测试集或人格/心理能力认证。复测仍有略显模板化的句子，后续应让目标用户评价舒适感、等待时间和被理解的程度。

## 当前输出限制

- 电话通常 20—65 字，最多 100 字；倾听文字最多 180 字，其他文字最多 240 字。紧急支持单独允许较长回复。
- 默认不追问，不每轮复述、夸奖或布置任务。用户拒绝建议、问题或要求停止时，要保留这些偏好。
- 诚实说明 AI 身份，不虚构记忆、真人经历、语气感知或招聘拒因，不许诺永久/排他陪伴或必拿 offer。
- 后端检查长度、最多一个问号、无 Markdown/动作表演及少数明确虚假承诺和无依据吹捧；最多重新生成一次，不截断后冒充完整回答。正则检查只能约束可观察格式与部分字面表达，不能证明所有语义都正确。
- 证据引文、来源修订和保存权限继续由应用校验，语言温暖不能代替事实依据。

## 可复现资料

入口为 `scripts/evaluate-companion.mjs`（固定情境）和 `scripts/evaluate-companion-holdout.mjs`（新情境及真实连续对话）。只在主动执行时调用真实服务，不属于自动测试，也不使用真实私人聊天。

本机原始证据保存在忽略目录 `.local/`：`companion-deepseek-baseline.json`、`companion-deepseek-final.json`、`companion-gemini-v7.json`、`companion-minimax-v7.json`、`companion-glm-v5.json`、`companion-holdout.json`、`companion-followup-v9.json`、`privacy-followup-v10.json`。记录包含合成输入、原始回复和耗时；后续复现会使用当前提示词，不能重现为旧版提示的同一次采样。
