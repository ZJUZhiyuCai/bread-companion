# 面包 · 前端设计概念：「深夜还亮着的面包房」

## 一句话

收到拒信的晚上，街上大多数灯都灭了，只有一家小面包房的窗还亮着。你可以进来坐一会儿、说几句，也可以只是看一眼就走。面包不催你，它在“醒面”。

## 隐喻，只用在视觉上

| 产品概念 | 视觉隐喻 | 界面文字（保持直白） |
| --- | --- | --- |
| 首屏 | 夜色里亮着的一扇窗，窗台上有一只闭眼的面包 | 今晚，先说说。 |
| 状态形象 | 面包本身：闭眼慢慢“醒面”=等待；被揉一揉=整理；冒热气=说；红点=录音；两道割纹变成暂停符=暂停 | 等待中 / 正在整理 / 正在说 / 正在录音 / 已暂停（**永远配文字，不只靠颜色或动画**） |
| 记号卡 | 牛皮纸面包标签，顶端是三道“割纹”（烘焙前在面团上划的刀口，就是“记号”） | 今晚的记号 |
| 复盘卡 | 带横线的配方卡 | 复盘卡 |
| 确认 | 一枚斜盖的小印章 | 已确认 · 第 N 版 |
| 失效 | 印章褪色，标签打上斜线 | 已过期 / 有异议，需要重新确认 |
| 结束 | 灯慢慢暗下去，面包睡着 | 今晚先停在这里。 |
| 本设备档案 | 柜台下面的抽屉，和桌上的“今晚”分开 | 本设备档案（存在这个浏览器里） |

隐喻只出现在插画、形状和动效里；按钮和状态的文字始终是直白的中文，不让人去猜“醒面”是什么意思。

## 视觉

- 纸张：面粉白 `#F8F4EC` 做底，墨色 `#22262B` 写字；面包皮棕 `#8C4B1F` 只用在强调和标签上。
- 珊瑚红只留给“录音中”和“停止”，不用大面积警报红。靛蓝 `#2B5C9E` 用于链接和焦点环。
- 夜色 `#1C2740` 只出现在窗景插画里。系统深色模式下整页变成“关了大灯的店里”，暖色依然保留。
- 字体：标题用系统宋体（Songti / Noto Serif SC），有一点手写信的温度；正文用系统黑体，不加载网络字体。
- 不做评分、仪表盘或进度条，因为没有什么需要“完成度”。

## 布局

- **桌面**：对话列居中，最宽 760px；右侧“今晚的材料”抽屉按需展开（有卡片生成时自动打开，但不抢焦点），三个标签页分别是记号、材料与依据、练一题。
- **手机**：单列。抽屉变成从顶栏下方滑出的面板，**顶栏不被遮住**，所以「停止」「结束」始终在同一个位置，随时点得到。
- **顶栏**是唯一固定的控制区：身份 + 当前状态、服务状态（规则演示 / 真实 AI）、记号、档案，最右边固定是「停止」「结束」。
- 模式条：倾听 · 留个记号 · 复盘 · 练一题。下面一行说明“这个模式会做什么、不会做什么”。
- 输入区：文字为主；录音、材料是两个小按钮。录音时整个输入区变成录音条（计时、上限、结束并转写、放弃），转写后变成可修改的草稿。

## 互动原则

1. **文字先到，声音后到**：欢迎词先以文字出现，播放由用户点击；播放中这条消息高亮，当作字幕。
2. **确认 ≠ 保存**：卡片上“确认这一版”和“保存到本设备…”是两个独立的步骤，后者一定先打开保存预览，逐项列出会存什么、不会存什么、实际引用了哪几段摘录。
3. **失效看得见**：来源修正后，引用旧版本的摘录标为“已过期”，卡片印章褪色并锁住确认和保存，同时给出“按修正后的内容重新整理”。
4. **不伪装**：等待模型时不放打字动画，只写“正在整理（结果核对后才显示）”；能力检查中就写检查中；语音不可用就照实写出原因。
5. **结束是真的结束**：结束页只读冻结快照；没有播放按钮，没有追问，没有问卷。

## 无障碍

- 所有触控目标至少 44×44px；焦点环 3px 靛蓝，带偏移。
- `prefers-reduced-motion` 时关闭面包呼吸、揉面、热气、灯光变化等全部动效。
- 状态形象同时有可见文字和 `aria-live` 播报；对话区是 `role="log"`。
- 键盘：Esc 停止当前回应、播放或转写；Enter 发送（输入法组字时不发送）、Shift+Enter 换行；所有弹窗用原生 `<dialog>`，自带焦点限制。
- 字号可以在“服务与数据”里调成大或特大，只在本次页面有效，不写入存储。

## 接入假设

- 唯一业务入口：`useBread()`（`@/services/use-bread`），返回 `BreadViewModel`。
- 卡片分区的 key 由 domain 决定，前端用宽松映射显示成中文标题；没有对应映射时直接显示 key。
- 是否成功以 hook 的 `notice` / `error` 为准，前端不自己宣布“已保存”。
