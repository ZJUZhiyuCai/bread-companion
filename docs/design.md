# 面包 · 第三轮前端：一个会听你说话的面包

> 把复杂留给 agent，把温暖留给用户。这一轮，温暖要有一张脸，也要有一个声音。

## 1. 角色：山形吐司「面包」

原创角色，不借用任何竞品形象。

- **轮廓**：一片山形吐司。两个圆鼓鼓的顶，像一颗有软耳朵的脑袋，金黄的边，奶油色的芯就是脸。远远看一眼就知道是面包。
- **一根麦穗呆毛**：从两个山顶中间长出来，它的情绪信号最灵：在听时竖起来，想事情时一点一点，出错时耷拉下来，挂着暂停时轻轻晃。
- **会动的身体**：短短的手臂、圆手、小脚、红脸颊，顶上的边皮有三粒芝麻。手的动作都对应实际状态：
  - 打招呼 → 挥手
  - 你在打字 → 双手托腮，眼睛往下看输入框（"慢慢写，我等你"）
  - 在听（通话/录音）→ 一只手拢在耳边，呆毛竖起；麦克风音量只驱动轻微点头和声波，**不解读情绪**
  - 在转写/在想 → 托下巴，眼睛往上看，头顶冒思考泡泡
  - 在说 → 摊开一只手，嘴巴开合，旁边有声弧
  - 你静音了 → 双手放在腿上，安静地等，挂一个静音角标
  - 暂停 → 捧一杯冒热气的杯子
  - 出错 → 挠头，皱眉，挂"!"角标；文字路始终可用
  - 结束 → 灯灭，睡着，飘 z
- **通话时戴上耳机**（带麦克风的小耳机），一眼就能分清"现在是语音"。
- 身份始终清楚：自我介绍就是"嗨，我是面包。一个 AI"。不做真人、不做排他承诺，表情只表达面包自己在做什么，从不声称读懂了你的情绪。

角色是纯内联 SVG（`components/BreadBuddy.tsx`），姿态、眼神、嘴型、呆毛、配件各是一层，由同一张状态表驱动；没有外部素材。

## 2. 两扇门：打字和打电话一样近

参考 `docs/companion-research.md`：Pi 让人轻松开口，Character Calls 一键双向语音、可以按键打断、文字语音来回切，Replika 首页一个电话图标直接进通话。我们只借鉴行为，不照搬品牌和素材。

- **首页**：灯下站着的面包先挥手说"嗨，我是面包"。右边主标题"今晚，先说说。"，下面两扇门上下排列：
  1. 写下第一句（纸条输入框）
  2. **给面包打个电话**，金色的大按钮，按钮下面有一句话说清楚怎么用："接通后直接说就好。你停一下，面包就接话；它说话时想插话，点一下就行。"
  其余入口（先听一小段 / 直接复盘 / 以前留下的）退成次要入口。
- **聊天页 · 桌面**：左边是"面包的角落"，灯下的面包实时反映状态，上面有它的一句话气泡，下面是电话大按钮；中间是对话；右边的卡片托盘照旧。
- **聊天页 · 手机**：顶栏下面一条"小栖台"：小面包 + 一句状态 + 醒目的"打电话"胶囊按钮。刚开始、对话还空着的时候，面包的话气泡里给几句可以直接拿来改的开头，外加一张电话说明卡。

## 3. 通话：灯调暗，面包戴上耳机

点电话 → `vm.startCall()`。整个会话页切换成深色的"夜间通话室"（同一套设计变量，在 `.is-calling` 下换成暗色），顶栏只留"结束"。

```
┌ 和面包语音中 · 03:12 ─────── AI · 网页语音，不是电话线路 ┐
│                      ◯ ◯ ◯（声波环）                      │
│                     戴耳机的面包                          │
│                       在听你说                            │
│           说完停一下，面包就接话；也可以点"说完了"         │
│   你：我其实不太想复盘……                                  │
│   面包：好，那今晚不复盘。                                │
│        [静音]       [说完了 / 插话]        [挂断]         │
│                 暂停 · 文字记录（n）                      │
└───────────────────────────────────────────────────────────┘
```

- **phase 驱动一切**：角色姿态、声波环（听你说时随 `level` 放大，面包说话时向外扩散，想的时候慢呼吸，静音/暂停时变暗）、阶段标题、提示句和中间那颗主键。
- **中间那颗主键随状态变化**：在听 → "说完了"（`heardSpeech` 之前不可用，提示"说完停一下也行"）；转写/想/说 → "插话"（`interruptCall`，按键打断，不假装全双工）；静音 → "打开麦克风"；暂停 → "继续通话"；出错 → "再试一次"（`resumeCall`，不自动无限重试，`call.error` 原样显示）。
- 左键静音（`toggleCallMute`，`aria-pressed`），右键红色挂断（`hangupCall`）。
- 字幕：上面一行小字是"你：最近识别到的话"，下面一行是面包说的话，大号宋体。桌面右侧常驻"文字记录"；手机上点"文字记录"在原地展开，不弹模态框，不遮住控制键。
- 挂断后回到文字聊天，焦点回到输入框；对话里插入两条分隔线"开始语音通话 / 通话结束 · 3:12"，字幕原样留在这段临时对话里。`结束` 仍然是结束整次对话。
- 通话期间旧的录音、手动播报、卡片托盘、档案入口都不出现，不争抢麦克风和扬声器；打开"关于"会先暂停通话。
- 不显示电话号码、不模拟"对方已接听"的真人感、不提供音色或供应商选择。"关于"里只写一句：声音固定为一种温暖的女声。

## 4. 语言

- 面包的气泡：短、口语、第一人称，只说自己在做什么："我在。""慢慢写，我等你。""嗯，让我想想…""先停一下。"
- 通话提示句子要能直接照着做："想插话随时点，它会马上停下来听你。"
- 不出现"配置、模式、模型、音色、任务"这类工具词。

## 5. 一直保留的东西

保存只发生在明确点"就留下这些"之后；挂断保留本页文字，结束或刷新清空未保存内容；来源纠正、存档、导出/导入/删除、卡片预览全部沿用。所有状态都有文字，不只靠颜色或动画；`prefers-reduced-motion` 时关闭动效和音量驱动的位移；键盘：Esc 停止/暂停，所有通话键都是真按钮，焦点可见；`forced-colors` 有描边兜底。
