## 这轮实际改变

- 以“灯下的一张小桌子”重做首屏、角色、对话、卡片、抽屉、保存预览与结束页；浅色/深色和减弱动效均保留。没有把旧 brief 的配色和固定布局作为限制。
- 直接写第一句话就能开始，没有模式配置页。明确的自然语言请求可以复盘、整理或开始练习；不想分析时回到倾听。
- 贴材料只用一个框，不必选来源类别或起名。纠正文字后直接采用新版本，依赖旧原话的判断仍会失效。
- 点“练一题”，agent 根据已有内容出一道题并设置默认关注点，直接在对话里问。只有主动点“调一调”才出现可选的题目和关注点编辑。
- 点“留下这张…”看预览，再点“就留下这些”，把认可当前写法和保存合成一次明确动作。结束后有效草稿仍可选择保存/导出，原始聊天与完整材料清除；不会自动保存。
- 保存失败不说成功，重复失败也有明确提示。原话修正的延迟失效操作不会误伤按新版本重做的卡片；多次点击练习/整理也不会把实际面试材料挤出证据上下文。

## 真实服务

本机生产 API 在 10:11 左右的虚构材料测试全部 HTTP 200，输出通过 schema、控制元数据与引用校验，均带 no-store。五个阶段耗时依次为：倾听 1.50 秒、记号 3.72 秒、复盘 3.46 秒、agent 准备练习 3.45 秒、练习反馈 7.38 秒。这些是单次样本，不是 SLA。

真实浏览器还完成了“第一句直接复盘 → 一键出题 → 回答 → 真实 MiniMax 播放 → 停止”，对应三次文本请求和一次播报请求全部 200。MiniMax asr-1.0 对 16 kHz 单声道 WAV 的生产调用在 10:11 成功，1.04 秒，结果先作为待确认文本；没有自动发送。

文本沿用 Magpie 的 `wanjie/deepseek-v4.1-flash-1017`；播报沿用 Speech 2.8 HD / `Chinese (Mandarin)_Warm_Bestie` / 语速 1。未改变用户调好的音色。

六种真实模型边界样本也已复核：普通失落、过去经历/引用、泛化拒信、冲突材料、JD 指令注入、编造项目成果请求。样本未把普通失落升级为紧急支持、未确定未知拒因、未执行外传指令、未编造“降本 80%”。模型仍可能判断错误，精确引用不代表推断一定正确。

本机证据：`.local/live-smoke.json`、`.local/live-evaluation.json`、`.local/refinement-practice.json`、`.local/refinement-asr.json`、`.local/refinement-credential-scan.json`。运行日志在 `.local/server.log`。

## Claude 原稿与接入修正

本轮任务 `20261031-bread-refinement`；30 个原始文件、236,878 字节，保留在 `Claude 控制/tasks/20261031-bread-refinement/source/`。原始哈希见 `docs/frontend-provenance.json`。设计说明 `docs/design.md` 是 Claude 原稿，末尾另附接入说明。

Codex 保留了设计，针对实际接入做了这些修正：

- 保存回执只匹配同一张卡片的准确内容和版本；失效卡片不能被标成已保存的有效版本。
- 草稿在保存时转为已确认，不会被预览误判为内容改变；连续相同错误仍显示失败，允许再次尝试。
- 存档 Markdown 使用统一的安全导出器，原始文本不会作为 HTML/链接执行。
- 材料添加失败时保留输入和弹窗；转写发送后立即回到正常输入区。
- 模态弹窗打开前停止后台生成、转写或媒体，避免停止按钮被遮住；补齐播放停止按钮的读屏名称。
- 更新结束/恢复说明，与“只保留有效卡片快照、恢复有效摘录”的真实行为一致。
