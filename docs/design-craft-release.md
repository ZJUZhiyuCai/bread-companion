# 面包细节设计 · craft release

实际运行与测试由 Codex 完成。本文是设计说明，不是验证结果：**本轮我没有运行构建、测试或浏览器，也没有看到改动后的画面**；下面所有“效果”都是设计意图，需要 Codex 截图确认。

## 方向（先写下，确认可写入）

现在的首页是一张对的草图：面包、红电话、一盏灯、一句话。平庸在于“材质缺席”——奶油色平铺的背景、四张同样的白圆角卡片、系统字体，像任何一个 SaaS 的空状态。这一轮不换方向，而是把同一个场景**做实**：

- **一张真的桌子。** 面包和电话坐在同一块被灯照亮的桌面上，灯光有核心、有衰减，远处是夜色。背景由纸纹、灯池、桌面、暗角四层组成，全部是 CSS/自绘 SVG，不引入素材。
- **字分三种手。** 谁在说话，就用谁的字。
- **每个组件是桌上的一件东西，而不是一张卡。** 便笺是有横格的信纸；“先听一小段”是一个小播放器；电话铭牌是老电话底座上的珐琅铭牌；会话、卡片、通话、弹窗用同一套纸、墨、黄铜、漆红。
- **安静优先。** 不加循环动效；所有新材质在减少动态、强制颜色、高对比、大字号下都退化得体。眼睛、电话模型、通话逻辑与所有回调不动。

## 设计系统（写在 globals.css 顶部的四条规则）

1. **纸几乎是方的，按的东西是圆的。** 纸类（便笺、卡片、材料、弹窗、档案卡）用 `--r-paper 5px / --r-sheet 10px`；按钮、药丸、通话键保持 999px。旧版几乎所有东西都是 16–24px 圆角，这是“像 SaaS”的主要来源。
2. **三种手，按谁在说话：**
   - 面包自己的话 → `--font-voice`（霞鹜文楷屏幕版，缺失时回落到 0.3.0 已在用的宋体）：首页标题与气泡、对话里面包的回复、开场 hello、伴侣角气泡、通话阶段标题与字幕、结束页晚安、卡片标题。
   - 界面与**你自己打的字** → 系统无衬线：按钮、标签、你的便笺和消息、安全提示（安全提示刻意不用面包的手，必须平实）。
   - 印刷品 → 宋体：引用原话、你放进来的材料、弹窗/托盘/档案这类“文件抬头”。
3. **只有一盏灯，在左上。** 所有阴影都是“接触线 + 向右下的长软影”，`--shadow-s / --shadow / --shadow-paper / --shadow-l` 全部重做。
4. **纹理、横格、边缘都是静态的。** 本轮没有新增任何循环动画。

## 本轮实际修改

只改了 `app/globals.css`、`app/layout.tsx`、`components/EntryScreen.tsx`、`components/BreadBuddy.tsx`。`Phone3D.tsx`、`phone3d/*`、services/domain/lib、所有回调、无障碍语义、语音/取消/重连/保存逻辑、图形 fallback 一行未动。没有新增依赖、远程资源或外部素材；`components/design/` 与 `public/design/` 本轮没有新增文件（所有纹理都是 CSS 内联的自绘 SVG）。

### 令牌与底层
- 墨色从偏蓝的灰黑改为暖棕黑（钢笔墨水），`--ink-3` 在 `--bg`/`--surface-2` 上按计算约 5.2 / 5.0 : 1。暗色改为暖黑（`#17150f`），黄昏冷色只留在远角。
- 新增：`--sheet / --sheet-edge / --rule / --floor / --vignette / --glow-core / --enamel(-2) / --brass-deep / --under / --edge-hi / --font-voice / --r-paper / --r-sheet / --ease-out`，以及三种自绘纹理 `--grain`（纸齿）、`--fibre`（牛皮纸纤维）、`--crayon`（一笔蜡笔下划线）。
- `body::before` 全页纸纹、`body::after` 暗角，固定在最底层、不接收指针；暗色下纸纹反相并用 soft-light。
- `--under`：“这张纸下面是什么颜色”。打孔、撕边、票根缺口都用它画，托盘与弹窗各自重设，所以收据锯齿在页面、桌边托盘、手机底部抽屉、弹窗里都和底色一致（旧版统一用 `--bg`，在托盘和弹窗里会露出色块）。
- CJK 排版：`text-autospace`、`text-spacing-trim`、`line-break: strict`，标题 `text-wrap: balance`、正文 `pretty`，首页/结束页标题允许句号悬挂。都是渐进增强，不支持的浏览器忽略。

### 首页
- 灯光三层：头顶附近的小热核 + 原来的宽光池 + 远角黄昏，再加一层地面渐变。
- **桌面**：`.entry__hero::before` 以原有“桌面线”公式（`--scene-top + --scene-w × 0.941`）为中心画出被灯照亮的木桌光斑，面包和电话同在其上；`.nook__table` 也加了朝灯一侧的亮斑。
- 标题用面包的手，并在“待一会儿”下面画了一笔柔和的蜡笔线（静态）。为此标题加了一个 `<span class="entry__title-mark">`，可访问名称不变。
- “先听面包说一小段”改成小播放器：左边黄铜圈布面喇叭，右边一个圆形播放键（`aria-hidden`，TTS 不可用时不显示，避免暗示会有声音）。
- 便笺改成**撕下来的一页便签本**：顶部胶条、几乎方角、下面露出下一页的边，textarea 上有随文字滚动的淡横格（`background-attachment: local`，行高与横格同一个变量，大字号下仍然一行一格）。
- **电话铭牌**改成老电话底座上的珐琅铭牌：象牙白珐琅、黄铜外框、内圈一道漆红细线、两端各一颗黄铜螺丝，红字。悬停时细线变亮、铭牌抬 1px，按下时沉下。被阻止时保留原来的虚线和去饱和，螺丝也随之变灰。
- 页脚两条“以后再说”的入口上方加一道细线，悬停时出现暖色下划线。
- 删除了已不再渲染的 `.ways / .way* / .entry__foot / .drawer-link / .doors` 样式（全仓 grep 确认没有组件使用）。

### 眼睛（唯一一处碰到面包本体）
- 当红电话就在旁边（首页、通话）时，每颗玻璃珠右下方多一小片暖红反光——**电话映在它眼睛里**。它和其他高光同组跟随视线反向微移，从不盖住瞳孔，不改变眼球形状，不闪。代码在 `BreadBuddy.tsx` 的 `.p-reflect`，只在 `lit && phoneLight` 时渲染。

### 文字对话
- 顶栏像书架边：发丝线下面多一线反光；控制按钮是纸质小键。
- 开场“今晚的对话从这里开始”改成信笺抬头：小字、宽字距、两侧渐隐细线。
- 面包的回复直接写在页面上（不加框），用面包的手；被朗读时用同一笔蜡笔色标出。“给你的一小段话”是一张明信片似的纸。
- 你说的话在你这一侧的牛皮纸条上：有纤维、靠你的那个角是方的，字仍是你打的字（无衬线）。
- 起头建议也是同一种牛皮纸条。
- 对话区上下边缘改用 mask 渐隐，不再在 dock 上方画一条纯色带（旧做法会把纸纹和灯光切出一条断层）。
- **写字区（composer）和首页便笺是同一本便签本**：顶部胶条、淡横格、几乎方角。发送键是和主按钮同一种“墨水键”：上有光泽、下有唇边、按下会沉。

### 卡片与材料
- 记号卡是**牛皮纸行李签**：纤维纹、左上光、打孔处有加固圈；支持 `corner-shape` 的浏览器会把挂孔那一角切成斜角，不支持时是圆角。
- 复盘卡是**小票**：白色热敏纸、顶部齿孔、底部撕边锯齿。
- 你放进来的材料是印刷纸，用一枚自绘黄铜回形针别在上沿。
- 引用原话是剪报：纸纹、左边暖色竖线、宋体。
- 失效卡片的斜纹背景修正了平铺尺寸（否则会继承纤维纹理的 320px 平铺而出现接缝）。
- 档案抽屉里每份是一张索引卡，左边的签子有加固圈；复盘类签子画成几行打印线而不是孔。空抽屉画成一块木质抽屉面和一个黄铜拉手。

### 电话与通话
- 伴侣角和对话里的电话入口、手机顶栏的“打电话”药丸，都换成同一种珐琅铭牌材质。
- 通话间：四周比灯下更暗（暗角），面包的字幕是被灯照着的一张卡，阶段标题用面包的手。
- 三个通话键改成**胶木键**：左上受光、右下暗、底下一圈深色底座，按下时下沉 2px。主键是灯的琥珀色并微微照亮周围；挂断键用电话本身的漆红渐变；静音按下时是墨色。尺寸和位置在任何阶段都不变（沿用原规则）。

### 弹窗、提示、结束页
- 弹窗是一张好纸：纸纹、亮边、向右下的长影；背后的房间暗成“傍晚”而不是灰色。标题加粗宋体（文件抬头）。
- 提示条是一张墨色小纸条。补上了 `Notices` 里用到但旧 CSS 没定义的 `.btn--secondary`。
- 结束页：灯调暗成夜灯的同时，远角的黄昏只进来一次（1.8s，不循环）；“今晚先停在这里。”和首页标题同一只手。

### 无障碍与偏好
- 焦点环、键盘路径、`aria-*` 都没有改。新增元素全部 `aria-hidden` 或纯 CSS 伪元素。
- `forced-colors`：纸纹、胶条、螺丝、回形针、锯齿、横格、蜡笔线全部隐藏，只留边框和文字；铭牌、便笺、播放器、档案卡补上了强制边框。
- `prefers-contrast: more`：去掉纸纹，横格和线条加深（明暗两套分别处理）。
- 减少动态：沿用全局规则；本轮没有新增循环动画。

## 字体：需要 Codex 取得并自托管

- **霞鹜文楷 屏幕阅读版 LXGW WenKai Screen**，作者 LXGW，**SIL Open Font License 1.1**，来源 https://github.com/lxgw/LxgwWenKai-Screen （Release 附件）。OFL 允许嵌入和自托管，需要随附许可证文本，不能单独售卖字体文件。
- 现状：`globals.css` 里的 `@font-face 'Bread Voice'` **只写了 `local()`**，本目录没有字体文件。所以除非用户本机装了这款字体，否则现在显示的是回落的宋体，也就是 0.3.0 的样子。**在 Codex 放好文件之前，不能说“文楷已经实现”。**
- 建议接入方式：
  1. 字体完整文件很大（屏幕版约 20MB 级），不能整包加载。按 unicode-range 切片（常用汉字 + 标点 + 拉丁），放到 `public/design/fonts/`，在同一个 `@font-face` 里加 `url('/design/fonts/….woff2') format('woff2')` 和对应的 `unicode-range`；或者用 `next/font/local` 在 `layout.tsx` 里注册，再把生成的 family 放进 `--font-voice` 的第一位。
  2. 保留 `font-display: swap` 和现有回落链，文字永远不会等字体。
  3. 许可证文件放在 `public/design/fonts/OFL.txt`，并在 README 的“第三方资源”里注明。
  4. 社区里有预切片的 npm 包（如 `lxgw-wenkai-screen-webfont`），但它属于未审查依赖。如果使用，建议只把审查过的切片文件拷进仓库，不作为运行时依赖。
- 如果用户最终不喜欢楷体，把 `--font-voice` 的前两项删掉即可回到宋体，其他设计不受影响。

## 需要 Codex 接入的逻辑变化

无。本轮没有改任何接口、状态或回调。唯一的 TSX 逻辑是首页播放键的显示条件 `!(caps && !caps.tts.available)`，只读已有的 `caps`；服务端首屏 `caps` 为 null，客户端首屏也是 null，不会造成水合差异。

## 请 Codex 验证

1. **三档截图 × 明暗**（约 1440 / 778 / 390px）：
   - 纸纹强度：应该“几乎看不见、但能感到纸”。如果看起来脏，把 `--grain` 里 feColorMatrix 的 `.55 0 0 0 -.2` 调成 `.45 0 0 0 -.18`，或者降低 `--grain-opacity`。
   - 桌面光斑是否正好托住面包的脚和电话底座（778px 时尤其要看）。
   - 蜡笔下划线落在“待一会儿”下沿而不是穿过字；换行时两段都有。
   - 铭牌在 390px 和大/特大字号下：螺丝不压字，铭牌照旧向左长。
2. **便笺横格**（首页与写字区，字号 标准/大/特大）：每一行字都应该坐在一条线上，第一条线在第一行字下方，而不是浮在字上面；写字区单行时只有一条“签名线”。转写确认框（`composer__input--boxed`）应该没有横格。
3. **眼中的电话**：在 120 / 220 / 480px 下看 `.p-reflect`。它应该读成“玻璃上映出的一点红”。如果读成斑点或瑕疵，把 `.p-reflect ellipse` 的 opacity 从 0.42 降到 0.3，或者删掉 `BreadBuddy.tsx` 里 `phone &&` 那一小段。
4. **收据锯齿与打孔**：分别在对话里、桌边托盘（≥1080px）、手机底部抽屉、保存预览弹窗、结束页里检查。锯齿和孔的颜色应该和下面的底色一致。
5. **通话间**：三个胶木键的立体感、按下下沉、主键的琥珀微光、挂断键的漆红、静音按下态；暗角不能压到字幕和按键的对比度。
6. **强制颜色 / 高对比 / 减少动态**：确认装饰全部退场、边框都在；结束页的黄昏渐入在减少动态下应该是瞬间完成的。
7. **性能**：全页固定纸纹层（暗色下带 soft-light 混合）和对话区 mask。在低端安卓上滚动长对话时检查是否掉帧。如果掉帧，先去掉暗色下的 `mix-blend-mode`，再考虑把对话区 mask 换回实色渐隐。
8. **CSS 工具链**：`corner-shape`、`text-autospace`、`text-spacing-trim`、`hanging-punctuation` 是较新的属性。如果构建或 lint 报错，可以直接删掉，它们只是渐进增强。
9. **E2E 选择器影响**（我没有改测试）：
   - 首页 `h1` 里多了一个 `span.entry__title-mark`，可访问名称仍是“先在这儿待一会儿。”。
   - `.rest-listen` 里多了一个 `aria-hidden` 的 `.rest-listen__play`。
   - `.dock::before` 已删除，改为 `.conversation` 的 mask。
   - `.ways / .drawer-link / .entry__foot / .doors` 的样式已删除（这些类名本来就不再渲染）。
10. **对比度抽查**：铭牌红字 `--phone-ink` 在珐琅上（计算约 6:1）、牛皮纸条上的字、暗色下 `--ink-3` 在 `--surface-2` 上（计算约 5.9:1）。以上是按色值计算的，没有实测。
