# 面包 · 同一盏灯下的材质与品牌（本轮设计判断）

2026-10-31。看过：用户截图 `reference/uncanny-eyes.png`（闭眼＝深色圆框里塞满毛纹）、实际首页 `docs/assets/bread-home.png`、`public/companion/bread-plush.webp`、`BreadBuddy / RedPhone / CallStage / Companion` 与相关 CSS。原图不进产品。

## 先查根因

| 现象 | 根因 | 处理 |
| --- | --- | --- |
| 眼睛停不下来 | ① 每 450–1900ms 随机 jitter，0.14s 过渡＝肉眼可见的跳；② 鼠标停 2.6s 后目标突然回正，超过 0.5 的跳视又 55% 触发眨眼；③ 每 90ms 用 `elementFromPoint` 判断“好奇”，电话一抖它就来回切，身体跟着上下 22 单位 | 删 jitter；注视改为“注视点”模型：只有目标变化超过死区才跳一次，然后停住；鼠标停下就继续看那里，6s 后才慢慢回到你身上；好奇改为事件驱动并带离开延迟 |
| 手放电话上一直抖 | hero 里按钮 `pointer-events:none`，只有子形状可点；悬停让听筒和整张 svg 位移 → 形状离开指针 → 悬停结束 → 复位 → 再悬停，形成反馈环，每次还重启转盘 nudge 动画 | 命中区改为一块**不参与任何变换**的静态轮廓；所有可见层 `pointer-events:none`；悬停只做一次性的“听筒微抬＋转盘高光”，不再重启动画 |
| 闭眼诡异 | 眼皮=眼窝上方的毛贴图＋深色描边＋阴影，留在一个圆形遮罩里；暂停/静音/睡着长期半睁或全闭 | 去掉所有眼皮。眼睛永远睁开；表情交给瞳孔、视线、头部姿态、腮红、嘴和小道具 |

## 判断

1. **眼睛＝玻璃安全眼。** 毛绒玩具真实的眼睛就是一颗深色玻璃半球，所以不再画琥珀色写实虹膜（太像在盯人）。新眼：深咖啡玻璃底、大瞳孔、暖棕虹膜只在光里隐约可见；顶部玻璃厚度的暗边、底部一弯“透光焦散”（光穿过玻璃打在底部，玻璃眼最有体积感的细节）、一块固定的窗形高光＋一个小星点。高光几乎不随视线移动——光在房间里，不在眼珠上。
2. **眨眼只保留一种，干净地发生。** 约 3.5–7 秒一次、180ms：整颗玻璃眼从上往下压扁成一条线，最低点出现一道向下弯的“‿”，再回弹。眼后垫一块羽化的毛（只有这 180ms 里看得到一条缝），没有描边、没有阴影圈，不会出现空洞圆片。减少动态时不眨。
3. **不闭眼也能休息。** 暂停：身体往下坐一点、往后靠、灯光收一点、眼睛平静地看着你；静音：同上＋静音小牌；出错：歪头、一颗小汗珠、眼睛看着你；结束（晚安）：灯调成小夜灯、身边一枚小月亮、眼睛睁着、腮红暖一点。
4. **同一盏灯。** 光源统一在左上方、偏暖。面包：用自身轮廓做遮罩，叠一层左上暖光与右下环境遮蔽，脚下是“紧贴的接触暗影＋向右下拖的柔影”。电话在面包右边，所以面包右下的毛上有一点**红色反光**；电话左侧的漆面上有一块**奶油色倒影**——两者互相照亮，才像在同一张桌上。
5. **电话重做为 3/4 俯视的漆面座机。** 分层：底座（顶面、正面、倒角高光）、机身（正面斜坡、左侧受光壁、右侧背光壁与边缘轮廓光、顶部平台）、凹进去的转盘井、象牙数字盘、带厚度的红色指轮（每个指孔有内壁阴影，转动时内壁始终朝上——用注册的 `--dial` 角度反向旋转）、黄铜指挡、穹顶中心盖（印品牌小标）、两只叉簧托与按钮、侧面立体听筒（拿起时换一套光照，不会“灯从下面打”）、真正绕圈的卷线（按曲线生成螺旋，拿起时圈距拉开，圈数不变）。阴影两层：接触 AO＋偏右下的柔影。
6. **配色。** 面包红 `#C8322B`（漆面中间调），高光 `#F07A5E`，暗部酒红 `#6E1418`；象牙 `#F4E8D2`；黄铜 `#C9A16A`；面包皮 `#B87A44`；墨 `#2A1D17`。只有电话和 logo 用到饱和红，界面其余保持纸与灯。
7. **Logo：一颗面包，头顶那撮毛是一圈电话卷线。** 原创矢量：奶油到面包皮的渐变身体、两颗带高光的玻璃眼、小笑口、红色卷线发旋（伙伴＋电话，一眼两义）。字标“面包”用圆头笔画手工构形，不依赖字体。交付：彩色横版（内置深色模式配色）、单独图形、单色版、红底 favicon；页面品牌入口用同一套路径的 React 组件。
8. **克制与可及。** 不新增文案或表单；形象全部 `aria-hidden`；减少动态时不眨眼、不追随、不晃，静态姿态仍区分状态；320px 无横向滚动；电话命中区清楚且只在电话本身。

## 本轮实际修改（Claude 原稿）

## 需要 Codex 联调

1. **悬停稳定性**：首页把鼠标停在电话边缘与听筒上，确认不再抖；`:hover` 只来自 `.rp-hit`（静态），面包的 `data-curious` 只在进入/离开时切换一次。
2. **眨眼观感**：在 120 / 220 / 480 px 下各看几次眨眼，确认毛片与周围毛色衔接、没有圆框。若某尺寸下仍可见接缝，可调 `BreadBuddy.tsx` 里 `-feather` 渐变的起点（0.84）或 `FUR` 采样偏移，不要恢复眼皮。
3. **浏览器差异**：Safari 中检查 SVG 内 `mask-type: alpha` 与 `mix-blend-mode`（失效时只是少了光，不影响结构）；`@property` 不支持时转盘拨号会跳变（Firefox < 128）；`d` 过渡不支持时卷线直接切换。
4. **性能**：带光照遮罩的面包只出现在首页场景、桌面侧栏、结束页和通话画面；小头像不加。低端机上看呼吸动画是否掉帧。
5. **e2e 选择器**：`data-state="asleep"` → `"night"`；`.p-lid*`、`.rp-cord__coil`、`.rp-cap__text`、`.rp-shadow` 已删（转盘中心不再有“面包”二字，改为图形）；`.wordmark` 的可见文字变为 SVG，`textContent` 仍含“面包”。按钮名称、`data-phone`、`.phone-door__btn / .call-pill / .plush / .cstage` 均未变。
6. 通话接通时刻、拨号节奏与上一轮相同（转盘 1.9s、之后每 2.2s 一次响铃），画面不等待声音。
