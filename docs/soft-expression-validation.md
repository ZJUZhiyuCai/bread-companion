# 表情与形象验收 · 2026-11-01

用户反馈：说话时嘴部不自然，希望形象稍微女性化。原照片自带缝线笑嘴，旧代码另叠错位椭圆嘴和舌头，且每 0.78 秒硬缩放。

## 交付

官方 Claude Code 设计原缝线开合、外眼角细睫毛、豆沙色腮红与毛毡花发夹。保留原照片身体与完整睁眼；去掉舌头、第二套笑嘴和说话时的快速弹跳。[原设计说明](design-soft-expression.md) 与 [源码溯源](soft-expression-provenance.json) 分别保留。

Codex 在实际朗读检查中发现动画阈值会跳过归零帧，留下 `--open: 0.002`、1% 不透明度；已强制绘制闭合端点。文字朗读增加准备状态，合成及浏览器播放等待期间不做说话动作，`audio.play()` 成功后才进入 speaking；后台、停止与迟到回调不能重启旧声音。

这里是轻微表情动画，仍非音素或声音振幅驱动的精确口型。麦克风音量属于用户，不用于面包的嘴。
