# 面包 · 本轮前端设计方案（实施前确认）

> Claude Opus 5.5，2026-11-02。基于 `docs/design/opus-premium-diagnosis-original.md` 与 Codex 的接续取舍（`docs/frontend-premium-diagnosis.md`）。
> 只有文件读写，没有浏览器。下面每一项都写明“改哪里”，Codex 渲染后按截图回修。

## 0. 一句话

**把“纸色背景板 + 一堆材质隐喻”换成「一个有地面、有光向的浅色布景」。** 毛绒和 Blender 电话本来就是摄影/渲染物件，它们天生属于这样一个空间：暖白的墙，向下弯成一块地面，左上方一盏大柔光，墙上落着一片很淡的窗光。界面里的东西只剩两类：**字**，以及**同一个棚里的几件哑光道具**（象牙色按键、一颗漆红挂断键）。

不变暗，不换卡通，不加抖动。眼睛保持正常睁开，配色保持浅暖。

## 1. 世界：柔光布景（取代纸面 + 噪点 + 灯晕）

| 层 | 做法 | 位置 |
|---|---|---|
| 墙 | 平滑的竖向渐变。左上方被柔光照亮，向右下渐渐落暗；右侧带一丝很淡的冷灰（傍晚的补光），形成冷暖对比，但整体仍是浅色 | `.entry::before`、`.session`、`.end` |
| 地面 | 从毛绒脚下一条**通栏的地平线**开始（圆弧过渡，不画线），比墙略深、略暖，越靠近观众越深。首页的文字栏和动作也落在这块地面上 | `.entry__hero::before`，用 `--scene-*` 算到脚线；`.entry` 改为 `overflow: hidden` 以便通栏 |
| 光池 | 物体脚下的一圈受光地面，加真正的接触阴影（沿用毛绒的 `p-ground` 和电话的 `rp-floor`）。**删掉毛绒身后居中的橙色光盘**，这是“抠图外发光”的来源 | `.nook__glow` 改为偏左上方的大面积墙面受光；`.nook__table` 改为地面光池 |
| 窗光 | 墙上一片 2×2 窗格的投影，模糊、很淡，光的方向与毛绒的主光一致（左上 → 右下）。这是“傍晚”的唯一线索，用光来表达，不把画面变暗 | `.entry::after`（首页）；结束页窗光更低、更暖，暗示时间过去了 |
| 质感 | `--grain`、`--fibre`、`--crayon` 全部设为 `none`。一处开关就能把全站的噪点、纤维和蜡笔线关掉，不会让引用它们的 `background` 声明失效。`body::before` 的噪点层删除 | tokens |

## 2. 同一部电话（解决 `user-call-plaque.png`）

- 新增 `PhoneStill`（写在 `RedPhone.tsx` 里）：**同一张 Blender 静帧** `bread-phone-rest.webp`，摆放在 RedPhone 的 260×220 宿主坐标里，与首页的海报完全同一套 `overlayBox(HERO_PHONE)`。SVG 只保留地面阴影和铃声标记（和 3D 叠加时的规则一致）。静帧加载失败时自动退回完整的 SVG 电话，**兼容回退保留**。
- 使用位置：聊天页桌面角落 `CompanionPanel`、空聊天、手机 perch 的胶囊、结束页的“打个电话”、结束页桌上的电话（`NightWindow`）。`PhoneGlyph` 不再用于常规画面，只保留导出。
- **通话页**：拨号、响铃、暂停、失败这几个 pose 用同一张静帧（SVG `<image>`，与绘制电话同坐标），振铃靠铃声标记与地面红光呼吸来表达，**不再整机晃动**。只有“听筒贴脸”（lifted）在 3D 就绪之前仍由 SVG 承担，因为静帧给不出这个姿态，而姿态必须如实。3D 的加载时机、引擎和相位映射都不动。
- 拨号盘中心盖上的品牌小面包删掉，改成素面象牙盖，与 Blender 模型一致。

## 3. 品牌与字形（解决 `user-header.png`）

- **标志 = 真的面包**：一枚圆形“联系人照片”，从毛绒照片里裁出脸部（复用 `BreadMark`，眼睛与主角完全一致）。它就是“你要打给的那个人”，和电话主题自然接上。卷线小面包退役。
- **字标 = 面包自己的字**：“面包”两个字直接用自托管的 Bread Voice（LXGW 文楷屏幕版）排出来。只用 400 字重，字距收紧。不再使用手搭的等宽圆头笔画。
- **品牌栏不再常驻“收到拒信的那个晚上”**。这句话移到首页标题上方，作为一次性的开场小字。
- “AI | 关于”从等宽字体的分隔胶囊，改成一行普通文字“AI · 关于”，44px 命中区。
- **两种字体**：系统黑体负责界面、你的话和文档；Bread Voice 负责面包的话和少数展示标题。`--font-serif` 指向黑体，等宽体只留给 `kbd`。全局 `font-synthesis-weight: none`，楷体只有一个真实字重，**不再出现伪粗体糊边**。这是现在标题发“糊”、显得廉价的直接原因之一。
- 静态品牌文件（`public/brand/*`、favicon）：毛绒剪影加两颗正常睁开的眼珠。favicon 用烤面包皮色的圆角底，在深浅标签栏上都能看清。字标 SVG 暂时用 `<text>` 加字体回退，**需要 Codex 用 fonttools 从 Bread Voice 转曲**（见 notes）。

## 4. 首页构图

- 左：毛绒和电话坐在同一块地面上，同一个光、同一组阴影。电话的“搪瓷铭牌”胶囊、扁平小电话和“→”全部去掉，电话下面只有一行展签式的文字：“给面包打个电话 / 用说的，不用打字”。**电话本身就是按钮**，命中区和 3D 逻辑不变。
- 面包的自我介绍从漫画气泡改成头侧的一段**字幕**（Bread Voice，不加框，不加尾巴）。
- 右：开场小字“收到拒信的那个晚上” → 大标题“先在这儿待一会儿。”（Bread Voice 400，去掉蜡笔线和短横线）→ 一句副标 → 三件事按代价排序：
  1. **先听一小段**：左侧一颗象牙色播放键，不再耳机图标和播放键各放一个。
  2. **写一句**：一块干净的哑光书写区，去掉胶条、横线和下面露出的纸。
  3. 电话在画面里。
- 页脚两条以后再做的事改成纯文字小链接，去掉图标。

## 5. 通话页

- 去掉三圈细线 `cstage__halo`，换成 `cstage__light`：毛绒身后墙上的一片柔光。听你说话时随音量**变亮、略微扩大**；面包说话时稳定地亮着；思考或转写时慢慢吸一口气。减少动态时只保留静态的相位差异。
- 字幕改成电影字幕：居中，面包的一句用 Bread Voice 大字，你的上一句用更小、更淡的黑体放在它上面。“你/面包”标签胶囊保留在 DOM 里给读屏用，视觉上隐藏。白卡片去掉。
- 状态标题降一级，“语音通话 0:12”去掉胶囊外框。
- 三颗键：静音和主键是象牙色哑光实心圆，阴影朝右下（同一盏灯）；**挂断是实心漆红配白色图标**，是画面里唯一和电话同色的控件。
- 次级操作改成纯文字一行，去掉图标。顶栏的“结束”语义不同（挂断并结束今晚），保留。

## 6. 不动的东西

`services/server/domain`、`phone3d/*` 引擎与布局常量；所有通话相位、权限、收音、打断、去重、恢复、草稿、停止/结束/重试/保存/复盘/练习的回调与语义；`aria-live`、`aria-disabled`、按键位置稳定；44px 命中区；减少动态；特大字；320px。没有新依赖，没有新字体，没有新位图，也没有新增文件（全部用现有素材完成）。笔试说明 HTML 不碰。

## 7. 风险与需要视觉确认的点

1. 通栏地面的地平线落在脚线上方约 16% 的位置，需要在 1440/1024/390/320 下看是否自然。
2. 窗光的强度。如果读成“形状”而不是“光”，就降低不透明度或加大模糊。
3. Blender 静帧在小尺寸（胶囊里约 34px）下的可读性。
4. 通话中静帧（拨号）→ SVG（贴脸，3D 未就绪）→ 3D 的切换。这是如实反映姿态的取舍，需要看一次真实拨号。
5. `--font-serif` 改为黑体后，卡片、引用、抽屉标题的观感。
