# 面包 · 会呼吸的小伙伴（本轮设计判断）

2026-10-31。参考：用户图（毛绒圆球＋玻璃大眼）、`public/companion/bread-plush.webp`（原创毛绒身体，眼窝留空）、Moflin / Mirumi / LOVOT 官网的动作与材质思路。只借鉴“毛绒＋玻璃眼＋细小反应”，不复制任何品牌角色；原图不进产品。

## 判断

1. **身体交给素材，生命交给眼睛。** 毛绒质感用位图最真实，所以身体就是那张图，不再用矢量去模仿毛。所有“活”的东西都在图上方用代码画：玻璃眼、眼皮、腮红、开口说话、呼吸与歪头。图、眼睛、阴影在同一个 1254 坐标系里，任何尺寸都不会错位，原图不拉伸。
2. **眼睛是三层玻璃。** 深色镜面底 → 会动的琥珀色虹膜和瞳孔（虹膜纤维、角膜缘、瞳孔缩放）→ 不跟着动的高光（光源在房间里，不在眼珠上；只有很小的视差）。上眼皮直接用眼睛上方那块真实的毛做填充，眨眼时“毛”盖下来，不是一块色块；下眼皮用眼下的毛，往上推就是笑眯眯的弯眼。
3. **注视有理由。** 眼睛只看三类东西：你（默认，正视屏幕外）、你正在用的东西（聚焦的输入框、按钮，手指点过的位置、鼠标）、它自己手头的事（想事情往上看，转写时左右扫，接通前看着电话，等麦克风权限时望向浏览器弹窗的方向）。加上细小跳视、偶尔四处看看、自然眨眼（随机间隔，偶尔眨两下，大幅转眼时顺带眨）。说话和“听到了”时保持对视，不追鼠标。
4. **状态只说它自己。** 在听：前倾、瞳孔放大，麦克风音量只驱动点头幅度；在想：眼往上、身子微晃、三个小泡；在说：嘴一开一合、轻轻上下；静音/暂停：眼皮半垂；出错：眼角下垂、歪一点；结束：闭眼慢呼吸。不读取、不推断用户情绪。
5. **红色座机是第二个角色。** 原生 SVG 分层：机身渐变与高光、底座、带指孔的转盘（单独旋转）、指挡、叉簧按钮、独立听筒、卷线。拨号 → 等待 → 拿起 → 接通是同一个物体的连续动作，全部由 `vm.call.phase` 驱动：`connecting` 时转盘拨两下然后电话响铃（循环，没有固定倒计时）；第一次真正 `speaking`/`listening` 时，听筒从叉簧上抬起，划一道弧，贴到面包脸边，叉簧按钮弹起，卷线跟着拉长；暂停时放回、斜搁着；出错时放回、褪色。
6. **一次点击。** 首页和侧栏的电话本身就是按钮（不是图标＋按钮）。悬停/聚焦时听筒微微抬起、面包转过来看它；点下即调用 `startCall`。不能打时电话褪色、听筒不动，原位写清原因，打字仍然可用。
7. **克制。** 首页只多一个可以“摸摸”的面包（真正的 `<button>`，名称“摸摸面包”，鼠标按下不抢输入框焦点），没有新增说明文字；通话页去掉耳机和光环里的旧面包，只剩面包＋电话＋状态＋字幕＋三个键。
8. **可及性。** 形象全部 `aria-hidden`，状态由文字承担；减少动态时不眨眼、不跳视、不追随、电话不摇不转，静态姿势仍区分状态；强制配色下按钮有边框。

## 与 Codex 的接缝

- 动画只读 `call.phase / heardSpeech / level / muted`；拨号音、开场语音、取消与暂停都在控制器里。电话“拿起”的时机就是 `connecting` 结束的那一刻。
- `connecting` 期间若已有开场字幕，会照常显示（不标为“正在说”）。

## 本轮实际修改（前端）

- `components/BreadBuddy.tsx` 重写：毛绒形象 `PlushSvg` / `BreadBuddy`（可选“摸摸面包”按钮）/ `BreadMark`（消息旁 30px 小脸）及眨眼、注视循环。导出名保持不变，`BuddyFigure` 不再导出。
- 新增 `components/RedPhone.tsx`（座机、`phonePose(phase)`、小图标 `PhoneGlyph`）与 `components/CallStage.tsx`（通话画面：面包＋座机同一 SVG）。
- `components/NightWindow.tsx` 的 `LampScene` 改为暖光小角落（去掉 `idPrefix`，新增 `pokeable`、`phone`）。
- `Companion.tsx`：`CallLauncher` 的 hero/panel 以座机为按钮，pill 用小座机图标；`EntryScreen.tsx`：电话移到首屏面包旁边；`CallRoom.tsx`：用 `CallStage` 替换戴耳机的面包与光环，接通前不显示“开个头就好”；`EndView.tsx`：睡着的面包＋放好的电话；`call.ts`：connecting 那句台词。
- `app/globals.css`：删除旧面包/台灯/旧电话按钮样式与只为它们服务的变量和关键帧，新增 plush / nook / red phone / cstage 样式，更新响应式、强制配色与减少动态。
- 未改：domain、services、server、prompts、tests、媒体 worklet、`vm` 契约与所有控制逻辑。

## 需要 Codex 联调

1. 真实链路下确认 `connecting → speaking` 的切换点就是开场声音实际开始播放的时刻（听筒在这一刻抬起）；若开场音频失败而直接进 `listening`，听筒同样抬起，这是预期。
2. 拨号音的节奏可以参考画面：转盘拨两下约 1.9 秒，之后每 2.2 秒一次响铃动作；不必对齐，画面不等待声音。
3. `resumeCall` 从 `paused` 回到 `connecting` 时会重新拨号（视觉上合理）；若想“续接”不重拨，需要一个区分标记，目前不需要。
4. 在 Safari 中检查：卷线 `d` 过渡不支持时会直接跳变（可接受）；SVG 内 `filter`（出错时电话褪色）可能不生效。
5. e2e 若有按旧类名找元素的用例（`.call-launch__btn`、`.callroom__halo`、`.buddy-svg`、`.lamp-scene`），需要改为 `.phone-door__btn` / `.call-pill`、`.cstage__halo`、`.plush`、`.nook`；按钮文案“给面包打个电话”“打电话”和可访问名称未变，新增一个名为“摸摸面包”的按钮（首页与桌面侧栏）。

## Codex 接入补记（与 Claude 原稿区分）

原稿已单独保留并记录 SHA256。320 px 实测发现首页气泡覆盖电话，因此接入版将移动端场景改为两列、气泡与电话各占一行，并微调电话标题字号；390 px 和桌面构图保留。另为通话画面增加容器宽度约束，避免从桌面缩到竖屏的过渡动画短暂撑出横向滚动。已用浏览器验证真实音频开始时听筒抬起、连接时转盘动画、挂断无迟到播报，详见 [验收](living-companion-validation.md)。
