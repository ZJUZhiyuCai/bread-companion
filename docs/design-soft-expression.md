# 面包 · 说话表情与形象细节（soft expression）

## 设计判断（先落盘）

**嘴为什么怪：** 照片原图在 (628, 640) 已经有一条缝线笑嘴，代码又在 (615, 642) 叠了第二张椭圆嘴加舌头——两张嘴、差 13 个单位，说话时那张假嘴以 0.78 s 的固定周期在 20%↔105% 之间硬缩放，身体同时 0.9 s 一跳。观感是"一张贴上去的嘴在嚼"，而不是毛绒自己在说话。

**方向：只有一张嘴，就是那条缝线。** 不再画第二张嘴，也不挪、不缩小它。说话时是原缝线本身"微微分开"：开口的上沿就是缝线（略盖住照片里的线迹），只有下沿往下张开；合上时开口完全消失，回到照片原本的缝线笑。招手 / 摸头的笑也是同一道缝开得稍大一点、停住，不再另画一张带舌头的嘴。

**说话的节奏要诚实。** 我们拿不到面包语音的音量，`level` 是用户麦克风，不能用来驱动口型。所以不假装对口型：`speaking` 期间按"短句"说——一句 1.4–3.4 s，句内音节 150–270 ms、开合幅度不等且偏小，句与句之间嘴合上停 0.4–0.9 s。没有固定周期，也没有大幅度，比原来更安静。身体去掉 0.9 s 的弹跳，只在每句开头轻轻抬起一点、句间放下，像人说话时自然的起伏。减少动态时：嘴保持一个静止的微张，身体不动。

**女性化往前推一小步，仍是毛绒玩偶：**
- 每只眼睛外上角三根刺绣式短睫毛，长在眼珠外面的绒毛上，不碰眼珠、不是眼皮，眼睛仍然全睁、形状不变。
- 腮红从珊瑚橘改成柔和的豆沙粉，更圆，位置更靠近眼下，默认更明显一点。
- 头顶那撮毛的根部别一枚小小的毛毡花发夹（豆沙粉花瓣、蜂蜜色纽扣花心、一片鼠尾草绿叶子），颜色偏灰调，不喜庆。

保留：照片毛绒身体、全睁开的玻璃眼、电话、现有 React 接口与生命周期清理。

## 实现

### 嘴（`components/BreadBuddy.tsx`）

- `SEAM = { cx: 628, y: 633, half: 37, dip: 15 }`：照片缝线的几何（两角 (591,633)/(665,633)，最低点约 (628,648)）。所有嘴形都由 `mouthShape(o)` 从这一条缝生成，`o` 为 0…1 的张开度。
  - 上沿 = 缝线上方约 2 个单位的同一条弧，用同色线迹（`.p-mouth__lip`，#7a3a1d，4.5 宽）盖住照片线迹；
  - 下沿的控制点随 `o` 下移（最多约 23 单位深），两角随张开向内收 3→7 单位，像两端仍缝着；
  - 内部是纵向渐变（缝口深褐 → 深处一点暖玫瑰色，代替原来的舌头），外加一圈很淡的"绒毛被撑开"的阴影。
- `o = 0` 时整组 `opacity` 为 0（CSS：`clamp(0, --open × 5, 1)`），画面上只剩照片原缝线——平静、暂停、静音、思考、夜晚都是这个样子。
- 已删除：`.p-smile`（带舌头的笑嘴）、`.p-mouth` 椭圆嘴和舌头、`@keyframes p-talk`、说话时身体的 `@keyframes p-bob`、`--smile` 变量。

### 嘴的动作（`useMouth`）

- 每帧直接写 path 的 `d` 和 `--open`，不触发 React 渲染；只在嘴在动时跑 rAF，停下后由 `MutationObserver`（`data-state` / `data-poke`）唤醒。
- `speaking`：短句 1.4–3.4 s；句内每个音节 150–270 ms，80% 幅度在 0.38–0.9，20% 只是微微分开（0.1–0.28）；句间合上 0.38–0.9 s。张开用 55 ms 时间常数、合上 85 ms，所以是软的，不是硬切。完全不读 `level`。
- 每句开始在 `<svg>` 上加 `data-phrase` 并换一个随机 `--tilt`；CSS 让身体抬起 7 单位、略倾 ≤0.8°（0.6 s 进），句间回落（1.2 s 出）。没有循环动画。
- `wave` / 摸头 `smile`：同一道缝慢慢开到 0.46 并停住；摸头 `wiggle`：开 0.2，一声小小的"哦"。进出的时间常数是 150/200 ms，比说话慢。
- `paused`、`muted` 等：目标 0，嘴在大约半秒内平静地合回照片缝线；从说话切到暂停也不会"啪"地闭上。
- 减少动态：说话时嘴静止微张 0.4，没有句子起伏；其余状态直接到位。
- 清理：取消 rAF、断开 observer、移除 media 监听，复原 `d`，移除 `--open` / `--tilt` / `data-phrase`。`alive=false` 的静态副本不启动，只显示照片缝线。

### 女性化

- 睫毛：`LASHES`，左眼外上角 128°/146°/163° 三根，长 28/33/27，尖端向上翘 14°/19°/24°（往上翘，不往下垂），根部在眼珠凹座外缘 1.04 倍处，右眼镜像。在 `.p-size` 内，跟随 `--eye` 一起缩放，但不跟 `.p-look` 移动；颜色 #2e170c、不透明度 0.84，像刺绣线。
- 腮红：#ef8c97 → #f29da3 豆沙粉，中心 (374,704)/(880,704)，80×50，比原来更圆、更靠近眼下；默认 `--cheek` 从 0.22 提到 0.3，各状态的相对强弱不变。
- 发夹：`public/design/soft-expression/felt-flower.svg`，五瓣毛毡花（锁边针脚、花瓣向花心收拢的阴影、细绒纹理）、蜂蜜色四孔纽扣（十字线）、一片鼠尾草绿叶子；光从左上来，影子落在右下的绒毛上，底边压了几缕绒毛。放在 `CLIP = { cx: 761, cy: 235, size: 150, rotate: -10 }`，在 `.p-breathe` 里跟身体一起呼吸、转头。

## 请 Codex 渲染时重点看

我这边没有浏览器/命令权限，以下都**没有实测**：

1. **缝线对位**：说话时把画面放大到嘴部，开口上沿应正好盖住照片线迹，不应在上方或下方看到第二条线。如有偏差，只改 `SEAM` 一处（`y`、`dip`、`half`）。
2. **发夹位置**：应落在头顶那撮毛根部偏右的绒毛上，不悬空在轮廓外，也不挡首页气泡（按截图估算约在页面 (360,210)，气泡左下角约在 (408,165)）。不对的话只改 `CLIP`。
3. **睫毛**：首页尺寸下应读作"三根细细上翘的线"，不能读成眼皮或眉毛；太重就降 `.p-lashes path` 的 opacity，或缩短 `len`。
4. **说话节奏**：至少看 20 秒以上的真实通话音频，确认没有明显周期感、身体起伏不晕；`speaking → paused → speaking` 切换时嘴平滑合上、再开始。
5. 摸头两种反应、`wave`、夜晚、减少动态。
6. 类型检查与 lint（`LASHES` 只用标量计算，避免 `noUncheckedIndexedAccess` 报错）。

## 以后可以做
