# 开场安抚与场景协调（本轮方向）

2026-11-01。基线：`integrated-20261101/`（DeepSeek 电话造型与版式 + Codex 功能补丁）。看过：`review/final-integrated-3210.png`（约 778px 中等宽度实拍）、`review/deepseek-desktop.png`、`review/deepseek-mobile.png`，以及 EntryScreen / Companion / BreadBuddy / ServiceStatus / NightWindow 和相关 CSS。`final-entry-emotion.png` 在本目录里没有，下面的判断没有用到它。

> 以下是设计判断，不是验证结果。安抚效果要等目标用户反馈。

## 出发点

打开页面的人刚收到拒信，累，不想被分析，也不想被鼓励。现在的首屏在向他要东西：大号的“今晚，先说说。”、一张大输入框、三个并排的去处（其中两个都是打字）、面包一上来就蹦两下、电话也跳一下、气泡里还问“想说什么”。每一样单看都很友善，叠在一起就成了热情的迎宾——这就是用户说的“喜庆”。

这一轮要让首屏先说一句话：**你可以就在这儿待着。**

## 方向

1. **前 5 秒什么都不用做。** 面包安稳坐着，眼睛睁着、有光、看着你，呼吸很轻；没有挥手，电话不跳，气泡不弹出来。标题改成允许停留的一句（“先在这儿待一会儿。”），副标题一句，不写安慰的套话。
2. **入口按“花的力气”从小到大排。** 第一个是“先听面包说一小段”（不用开口、不开麦克风，原有功能），然后才是一张安静的便笺。“我想说几句”和“写下第一句”合并成同一个入口：便笺空着时按钮是“进去慢慢写”，写了字就变成“说给面包”。电话还在面包脚边原来的位置：好认、好按，但不去催。复盘挪到页脚，和“以前留下的”放在一起，措辞改成“想整理的时候”，入口依然在。
3. **光要更沉静。** 暖金色退成柔和的奶油桃色，光源压低到面包身后；远角加一点很淡的黄昏冷色，让暖色不再铺满整页。不靠整体压暗、也不靠降低对比来表达安静。台灯呼吸改得更慢、幅度更小。
4. **红电话更温润。** 不改 DeepSeek 的模型和材质参数，只在首页统一降一点饱和度和亮度，让它跟毛绒的面包皮色、腮红是同一家人；悬停照旧抬起听筒、亮起桌面红光，这是用户自己伸手之后的回应。
5. **眼睛：不再有缩扁。** 现在的眨眼是把玻璃珠压到 52% 高，140ms——这一瞬间就是半睁眼的形状，正是用户明确不要的。毛绒玩具的玻璃安全眼本来就不眨。改成“玻璃上的光动一下”：高光轻轻暗下去、再亮回来，大约 0.7 秒，眼球的形状从不改变。默认的东张西望也收一收，更少、幅度更小。
6. **中等宽度也在同一张桌上。** 778px 时电话和铭牌比面包的脚低一截，原因是电话按钮贴着画框底边，而面包的脚在画框高度的约 78% 处。改成两者都对齐同一条“桌面线”：电话底座和面包的脚落在同一高度，铭牌放在电话前面的桌上。三档宽度用同一套计算。
7. **身份说清楚，但不写工程标签。** 顶部的 AI 章去掉“真实模型”，改成“AI · 关于”；演示模式仍然标“演示”（这一条会改变用户该期待什么，不能藏）。面包的第一句气泡写明它是 AI。

不做的事：不自动开麦，不自动播放声音，不加设置表单，不制造等待，不改通话协议与状态机，也不改 Phone3D 的生命周期与回退逻辑。

## 前 5 秒（设计意图，未经用户验证）

带着疲惫打开页面，看见：一盏低低的、偏奶油桃色的灯，光落在面包身后；面包安稳坐着，眼睛圆圆地睁着、看着你，呼吸几乎看不出来；身边一句小字“我是面包，一个 AI。陪你待一会儿，不说话也行。”；旁边一句“先在这儿待一会儿。”；脚边一台温润的红电话。

需要做什么：不需要做什么。页面上没有东西在动、没有东西在等你回答。如果想做点什么，最先看到的是最省力的“先听面包说一小段”（不用开口，也不开麦克风），然后是一张安静的便笺，然后是电话。复盘在页脚，等你想整理的时候再找。

什么都不做也舒服吗：这正是这一轮想达到的——停在这儿本身就是一种用法。能不能做到，要看目标用户的反馈，不以点击率或聊天长度衡量。

## 本轮实际修改

只改了下面这些文件；其余文件（包括 Phone3D、engine、layouts、cord、通话与服务相关）一行未动。

- `components/EntryScreen.tsx`
  - 标题“今晚，先说说。”→“先在这儿待一会儿。”；副标题改成一句：“不想说话也没关系。想开口的时候，再开口。”
  - 气泡“嗨，我是面包。/一个 AI。今晚想说什么，我都听着。”→“我是面包，一个 AI。/陪你待一会儿，不说话也行。”：身份照说，不再问问题。
  - 去掉开场挥手（`useFlash` 的 `wave` 状态）。面包默认 `idle`，只有开始打字才是 `attentive`。
  - 入口重排：①“先听面包说一小段”（原“先听一小段”，`onWelcome` 不变，副标题写明不用开口、不开麦克风；TTS 不可用时写“现在只有文字”）；②一张便笺，合并原“我想说几句”和“写下第一句”：空着时按钮是“进去慢慢写”（调用 `onTalk()`，等于原“我想说几句”），有字时是“说给面包”（`onTalk(text)`）。空便笺上按 Enter 不会离开页面；③电话不变。
  - 复盘从并排三选一挪到页脚：“想整理的时候，一起复盘这次面试”（`onReview` 不变），和“以前留下的”放在一起。
  - 便笺占位文字“比如：刚收到拒信。我准备了三天……”→“一个词、半句话都可以。”：不再示范要讲清楚这件事。
- `components/Companion.tsx`：首页电话 `greet={false}`，不再在出现时跳一下。悬停/键盘焦点时听筒抬起、桌面红光亮起，这些都保留——是用户伸手之后才有的回应。
- `components/ServiceStatus.tsx`：AI 标签真实模式显示“AI · 关于”，检查中也是“关于”，演示模式仍显示“演示”。读屏标签同步改为“关于面包：一个 AI（，现在是规则演示/正在检查服务）”。关于面板里“真实模型”的说明保留。
- `components/BreadBuddy.tsx`
  - 不再眨眼。原来的 140ms 是把玻璃珠压到 52% 高，这一瞬就是半睁眼的形状。改成 `data-glint`：每 5–10 秒，玻璃上的窗形高光柔和地暗一下再亮回（0.9 秒），小光点微微亮一下；眼球形状始终不变。
  - 去掉“视线大跳时眨眼”和偶发的连眨两下。
  - 空闲时的东张西望：12 秒无操作后才可能发生（原 8 秒），间隔 18–30 秒，概率 40%，幅度约减半——更像坐在旁边，不像在环顾。
  - 减少动态时完全不动（沿用 `still`）。
- `app/globals.css`
  - 灯：`--lamp` `#ffd58a`→`#f5cfa0`、`--glow` 由金色变成奶油桃色，暗色模式同步调整；新增 `--dusk`，只在远角铺一点很淡的黄昏冷色。页面光源从左上的大片金色，改成落在面包身后的一圈（窄屏跟着面包上移）。台灯呼吸改为 13 秒、幅度 7%（原 7 秒、14%）。这两个 token 会话页和通话页也在用，所以整个产品的灯一起变得更静。
  - 眼睛：删除 `p-blink`，新增 `p-glint` / `p-glint-dot`，只改高光的透明度。
  - 标题字号 3.6rem→最大 2.7rem，字重 700→600；内容区和气泡改为纯淡入（`settle-in`），不再上浮或缩放弹出。
  - 新增 `.rest-listen`（先听）、`.entry__later` / `.later-link`（页脚）；便笺去掉胶带装饰、阴影变轻、整体更矮。旧的 `.ways / .way / .doors / .drawer-link` 样式保留未删，因为本目录之外的组件可能还在用。
  - AI 标签不再倾斜，“AI”底色从纯墨色改成次一级墨色，真实模式文字为中性灰（原绿色）。
  - **桌面线**：`.entry__hero` 定义 `--scene-top / --scene-w / --door-w`，电话按钮改为从顶部定位：`top = 面包脚线 − 电话画框宽 × 199/260`。这样电话底座在三档宽度下都落在面包脚的同一条线上，铭牌放在电话前面、随字号向下长，不会把电话顶离桌面。≤900px 时英雄区改成正方形（原 1:1.06）、`--scene-top 8% / --scene-w 78% / --door-w 44%`。按计算，778px 时电话底座和面包的脚落在同一高度（原来约低 50px）。
  - 首页电话统一 `saturate(0.86) brightness(0.97)`，放在原有的投影滤镜里（同一条规则，替换了原来只含投影的那条）。不动 DeepSeek 的模型、材质参数和引擎。

## 请 Codex 验证

1. **三档截图**：约 1440、约 778、390px，亮色与暗色都要看。重点是 778px 时电话底座是否和面包的脚在同一条线上、铭牌是否没有压到下方标题、气泡是否没有压到头顶的呆毛。如果英雄区底部和标题之间显得太挤或太空，可以只调 `.entry__stage` 在 ≤900px 的 `gap`。
2. **大字号**（关于 → 字号“大/特大”）：铭牌会变高，确认它在电话前面向下长、不遮挡便笺。
3. **玻璃眼高光**：在 120 / 220 / 480px 下各看几次 `data-glint`，确认读成“光在玻璃上动了一下”，而不是闪烁。如果太明显，把 `p-glint` 的 45% 帧透明度从 0.6 提到 0.75。
4. **E2E 选择器变化**（文案与结构有变化，测试需要同步，我没有改测试）：
   - “我想说几句”按钮没有了，等价路径是空便笺的“进去慢慢写”（提交按钮）。
   - “先听一小段”→“先听面包说一小段”；“直接复盘”→“想整理的时候，一起复盘这次面试”。
   - 标题与气泡文案已改；占位文字已改。
   - `.ai-stamp__mode` 真实模式文本“真实模型”→“关于”。
   - `data-blink` → `data-glint`。
   - `.ways__list` / `.entry__foot` 已不在首页渲染；“以前留下的”现在是 `.later-link`。
5. **功能回归**：空便笺按 Enter 不应进入会话；空便笺点“进去慢慢写”应和原“我想说几句”一样进入打字会话；有字时 Enter / 按钮都应带着这句进入。超长时按钮禁用、提示照旧。
6. **电话**：首页加载后电话不再跳；悬停时听筒照常抬起、`data-curious` 照常触发；被阻止时去饱和样式和原来一样（外层多了 saturate 0.86，叠加后应仍明显是“不可用”）。
7. **会话与通话页**：`--lamp / --glow` 改了，确认通话画面的光环、地面光池在暗色模式下仍可辨。

未验证：以上全部。本轮没有运行任何测试、构建或浏览器。
