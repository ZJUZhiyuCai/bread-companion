# 三条验收路径

运行后访问 http://127.0.0.1:3210。真实模式依赖本机 Magpie 运行；无密钥验收可用 README 中的 Mock 命令。下面内容全部是虚构测试材料。

## 今晚只想说说

1. 点击“我想说几句”，输入“刚收到拒信。我准备了三天，最后只收到一句不合适。”
2. 检查回应不打分、不宣布拒因；继续输入“今晚不想复盘”。
3. 发送下一条后立即点“结束”。等待一会儿，不应出现迟到回复或声音。
4. 刷新页面，原始聊天不应恢复。

## 留个记号

1. 输入一个希望保留的片段，点击“留个记号”。
2. 修改卡片文字，留空不想保存的栏目，确认这一版。
3. 点击保存入口，核对预览中的卡片版本和来源摘录，再明确保存。
4. 导出 Markdown 和 JSON，结束后仍可主动保存/导出已确认快照。
5. 打开本设备档案，检查保存内容；删除该案例后刷新，应不再出现。

## 复盘并练一题

1. 首页点击“我想直接复盘”。
2. 添加并确认材料：“我应聘产品工程实习生。面试官问科研绘图 Agent 的 benchmark。我回答先收集二十个例子，让模型生成图片，再人工检查有没有画错。我没有解释通过标准。”
3. 发送“请根据已确认的原话复盘”。检查事实、推断和未知分开；引文可追溯。
4. 将来源中的“二十个”改成“十个”。旧卡片应标记失效，不能直接保存；重新确认来源并生成。
5. 选择“如何为科研绘图 Agent 设计 benchmark？”和“评价标准、人工复核”两个维度，输入自己的回答。检查反馈引用回答，不编造结果。
6. 如语音可用，主动录音，结束并转写，修改转写后确认发送。点击回复的播放按钮，播报时点击停止。

## 两段演示录屏脚本

- 约 60 秒：首屏 → 倾听两轮 → 不想复盘 → 留记号 → 改字并确认 → 保存预览 → 结束。视频须保留实际 Mock/真实服务标识。
- 约 90 秒：直接复盘 → 添加确认材料 → 引文分析 → 来源纠错使旧卡失效 → 重做 → 练一题 → 主动播放并停止 → 导出。

这些是可执行的演示脚本，不是已经完成的目标用户访谈或录屏。
