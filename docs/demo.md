# 面包验收路径

访问 http://127.0.0.1:3210。真实模式依赖本机 Magpie；无密钥验收可用 README 的 Mock 命令。下面都是虚构测试材料，不需要先配置材料类型、题目或练习维度。

## 只想说说

1. 直接在首页写：“刚收到拒信。我准备了三天，最后只收到一句不合适。”，点击“说给面包”。
2. 检查回应不打整体分、不宣布拒因；继续说“我现在不想分析了，只想说说”。
3. 发送下一句后立即点“结束”，不应再出现迟到回复或声音。
4. 刷新，原始聊天不会恢复。

## 打个电话，再接着打字

1. 首页点“给面包打个电话”，允许麦克风。说“今天有点累，先不想复盘”，说完停一下。
2. 查看“在听 → 嗯，让我想想 → 面包在说 → 在听”的状态，语音和字幕应对应。等待期间直接开口也能中止旧回应。
3. 面包播报时直接说“等一下，我想说的是……”，不点按钮：旧声音应停，开头应完整进入下一句。也可验证备用“插话”按钮。静音后不应上传新录音，再点静音键或“打开麦克风”继续。
4. 暂停或切换到别的页面，麦克风应关闭；回到页面需要主动点“继续通话”。
5. 点“挂断”，文字记录仍在，输入框获得焦点。可以接着打字；再点“结束”才结束整个会话。
6. 拒绝麦克风权限时应有重试和挂断入口，不出现假接通；首页未写完的文字应保留。

## 留一个记号

1. 聊过一段后，点“留个记号”。卡片出现在对话里，可直接查看。
2. 想改字、删一栏时点“看看 / 改改”；依据折叠在卡片里，需要才展开。
3. 点“留下这张…”查看真正会保存的内容，再点“就留下这些”。不用再走一次确认卡片流程。
4. 没保存就结束，也可以在结束页留下已经展示的有效卡片；结束不会自动保存或生成新总结。
5. 在“以前留下的”中查看、导出、恢复或删除；JSON 可导入回当前浏览器。

## 看一段回答，再练一个小地方

1. 直接告诉面包：“帮我复盘：我应聘产品工程实习生。面试官问科研绘图 Agent 的 benchmark。我回答先收集二十个例子，让模型生成图片，再人工检查有没有画错。我没有解释通过标准。”
2. 或点击回形针粘贴这段材料，再点“看看那段回答”；不必选择来源类别或命名。
3. 查看卡片，展开依据检查引文。改正材料中的“二十个”为“十个”，旧卡片应失效；点击重新整理即可。
4. 点“练一题”。面包根据刚才的内容直接问一道题。写下真实回答，检查反馈依据本次回答，不编造结果。换题和手动调整都是可选项。
5. 如语音可用，点麦克风，说完后点“说完了”，修改转写再“发出去”。回复只有点击“听”才播放，随时能停止。

测试包含取消、错误、存档和恢复路径，但不能代替目标用户访谈或真机兼容性走查；实际证据见 acceptance.md。
