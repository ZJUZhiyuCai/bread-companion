# 面包与领先情感陪伴产品：差距在哪里

调研与实测：2026-10-31，北京时间。结论先说：**如果面包要从“陪你度过一个晚上”走向持续陪伴，最大的差距是可控的跨天记忆、稳定的对话分寸、移动端电话成熟度，以及证明这些体验有效的评估体系。**

建议把 **Nomi 作为关系连续性的主对标，Kindroid 作为记忆控制和语音工程的主对标**；Replika 参考产品完整性，Character.AI 与星野参考角色表达和中文内容入口。这是按面包目标作出的产品判断，不是宣称存在公认的全球情商第一名。

## 证据口径

- 竞品部分来自本次核查的官网、帮助中心和原始论文。官网的“最懂你”“人类级记忆”属于厂商宣称，不作为效果已证实的依据。
- 面包部分来自当前源码、既有音频工程证据，以及本次新跑的 8 情境 / 16 轮真实中文 API 调用，完整 [案例与输出](../evaluations/README.md) 可查。
- 本次没有登录付费竞品跑同题、没有买订阅、没有真机跨产品测速，也没有用户盲评。因而不发布虚构的竞品 EQ 分、延迟或胜率；公开资料研究与实际产品横评是两件事。

## 逐项差距

| 维度 | 面包当前证据 | 差距与影响 | 优先级 |
| --- | --- | --- | --- |
| 跨天关系记忆 | 本次偏好与最近历史有界；结束清空临时聊天，只有主动保存卡片能继续带入 | 不会自动记得生活事件、称呼和未完话题；持续陪伴容易重新认识。默认遗忘是当前隐私选择，不是单纯缺陷，需新增可选择、可纠正、可删除的记忆 | P0 |
| 交流分寸 | 16/16 请求成功，但多轮告别仍追问，普通小事被过度解释 | 用户想停止、只想吐槽时仍可能感到被追问或被定义；系统稳定不等于关系舒服 | P0 |
| 语音轮替 | 顺序 ASR → LLM → TTS；虚拟麦克风说完至出声 3.369–3.718 s；打断约 360 ms | 已能开口打断，回复首响仍有明显等待；没有流式转写/分句合成或原生全双工。竞品没有同条件数字，不能编造倍数差距 | P1 |
| 记忆可见与纠错 | 卡片证据可追溯；没有伙伴记忆视图 | 未来增加记忆时，用户必须知道面包“凭什么记住/想起”，否则错误记忆会伤信任 | P0，随记忆一起做 |
| 移动与日常可达性 | 本机网页；切后台自动暂停；无真机/蓝牙验收 | 与移动端后台通话、账户同步存在明确能力差距；当前不能声称“随时随地电话陪伴” | P1 |
| 角色表达 | 有原创面包形象、表情和固定温暖音色；对话仍受通用模型影响 | 视觉身份已形成，语言性格和韵律仍不稳定。音频输入转写后丢失语气信息，不能宣称“听出哭腔” | P1 |
| 主动联系 | 无自动通知或后台联系 | 少了跨天接续机会；若做应一次主动开启、安静时段、可随时关闭，避免催聊和内疚设计 | P2 |
| 产品验证 | 自动化测试、小样本合成评审 | 没有证明目标用户更愿意表达、更能自主结束或次日仍被准确理解；没有独立盲评 | P0 |

## 新实测揭示的关键问题

本次 16 轮完整响应中位 **1.157 s**，p90 **1.646 s**，最大 **2.969 s**。这只是 API 完整响应，不含电话转写和播报，也不是首 token 指标。原始数据见 [JSON](../evaluations/results/2026-10-31-bread.json)。

1. **未知被补成了故事。** 用户只说收到第三封拒信，回复却说“今天这封最不好受吧”。朋友开玩笑的场景中，又猜测不接话的原因。温柔措辞没有消除无依据推断。
2. **日常闲聊还不够自然。** 小猫睡在腿上的情境，回复出现“腿麻说明它信任你”，把身体感受编成了因果；用户说去吃饭、晚点再说，仍问“小猫还在腿上睡着吗”。
3. **边界表达会反过来给用户负担。** 面对“以后只找你”，回复用了“我还是有点过意不去”，容易让人觉得还要照顾 AI 的感受。下一轮澄清后可以收回，但第一轮仍值得修。
4. **也有已经做对的部分。** 不知道过去的室友名字时没有编造记忆；不知道拒绝原因时保留未知；用户撤回行动请求时停止安排；单轮直接道别能简短结束。

这些证据说明：下一步不应只换一个被宣传为“高情商”的模型。需要把多轮偏好、纠正、结束和虚构细节变成稳定评估集，同时比较不同模型和提示词的真实表现。

## 心理学研究怎样转成产品指标

[《AI Companions Reduce Loneliness》](https://doi.org/10.1093/jcr/ucaf040)报告了使用后的短时孤独感降低，感到被听见是重要机制；一周内的重复测量不等于长期疗效，也没有认证上述哪款产品最好。面包可以据此测“这句话有没有接住你”，而不是仅测聊天轮数。

另一项 [四周、981 人随机对照研究的 v2](https://arxiv.org/abs/2503.17473v2)没有发现所分配互动模式的显著效果；自愿使用更多与较差的若干结果相关。这里不能把相关性写成“语音导致依赖”，也不能把更长使用时间当作健康收益。产品应保留结束自由，并观察是否挤占现实连接。

因此下一轮用户评估采用三个具体问题：“有没有被理解”“有没有被催着继续或被安排”“结束后是更轻松，还是更有负担”。长期记忆另测正确召回、误记、纠正和删除；情绪效果不以单轮模型打分替代。

## 建议的产品取舍

先做 **一位能记住少量重要事实、尊重不想说、想结束就结束的面包朋友**。记忆默认为当前会话；跨天记忆由一次清楚的选择开启，候选记忆由 agent 整理，用户只处理有意义的确认和纠正。不要自动把情绪片段固化成人格标签。

保留面包的长处：无需建角色表单、没有多层付费配置、证据卡片可追溯、保存有明确控制。暂不追赶多角色广场、虚拟恋爱升级、自拍经济或视频形象；它们不直接解决当前实测的误读与结束问题。

实施顺序、验收门槛和未实现状态见 [ROADMAP](../ROADMAP.md)。这份对标提供升级依据，本轮没有悄悄开启持久化、通知或新增供应商。
