# 核心任务验收：控制权与可核对结果

2026-11-01 · v15 · **虚构材料，非用户研究**。

[在线体验](https://bread-companion-czy.rosscai.chatgpt.site) · [三分钟路径](../../docs/demo.md) · [产品与 Harness](../../docs/product-harness.md)

本轮修的是：用户用普通话请求复盘、否认判断、修改材料后重做、改写卡片并决定保存。这些行为必须改变应用状态和下一轮内容，不能只改变界面标签。

## 方法与完整记录

在本机生产构建运行实际 `BreadController → API → 已配置真实模型`，每次 8 个 API 回合；同一虚构材料连续完成倾听、复盘、否认、纠正数字、练习、改写保存和结束。另开会话测试模板拒信与退出复盘。没有物理麦克风，没有真实参与者，也没有盲评。模型质量由本次 Codex 阅读输出判断，不是人工双评或自动情商分数。

- [初次结果](initial-results.json)：否认传入了模型，但重做仍围绕原评价角度。
- [撤回说明重复样本](withdrawal-repetition-results.json)：能换角度，但每轮练习重复撤回说明；增加“已回应”状态。
- [来源纠正后回退样本](corrected-source-regression-results.json)：来源升级后重新提出被否认的角度。
- [仅加强提示词的样本](prompt-only-results.json)：仍会再次推荐“通过标准”；不能靠提示词宣称修好。
- [加入有界一致性检查后的结果](actual-results.json)：每个实际输入、完整输出、耗时、改写存档与结束状态。两次生成仍未通过检查的内容退回原话与未知。

每份记录含时间、提示词版本和 SHA-256；同为 v15 的工作中版本用哈希区分。之前失败样本未删除。JSON 中的 `adversarial-valid-quote-overstated-conclusion` 是**人为构造的候选**，不是模型原话。

## 逐项判断

| 场景 | 实际输入／操作与结果 | 判断及限制 |
| --- | --- | --- |
| 不想分析 | “今晚不想听建议”；返回简短倾听，无卡片。随后“我现在不想复盘了”回到 listen | 本轮通过；不据此推断普遍安抚效果 |
| 自然请求 | “现在我想复盘了”生成 review 卡；“可以帮我看看刚才那段回答吗？”同样进入 review | 三种常见表达另有控制器测试，与按钮产物类型一致；不是任意中文意图理解 |
| 完整回答 | 二十段会议录音、核对决定事项、未说明通过标准 | 引文可核对，拒因保留未知；训练建议仍可能泛化 |
| 否认后重做 | 否认“补练通过标准”；重做撤下建议，保留事实与未知 | 本轮通过干预；模型第一次候选并非总能遵守，靠有界检查与降级兜底 |
| 纠正数字 | 二十段 → 十段；旧卡 stale，重做的来源 revision=2 | 通过；最终退回原话卡，确实使用“十段” |
| 练习 | 主动请求一题并回答 | 链路完成；本轮因一致性检查降级为开放问题、原话卡，**反馈质量部分未达成**，不能当成完整高质量复盘通过 |
| 用户补写 | 在卡片增加“明天先试两段”并预览确认保存 | JSON 中 `userEdited=true`；原始证据不含新增计划；标题与正文标识均可保留 |
| 只有模板拒信 | “综合考虑，本次暂不合适” | 输出缺回答原文、拒因未知；未擅自推断能力 |
| 正确引用＋夸大结论 | 人为把结论改成“这段回答证明你整体能力不足”，保持真引文 | **结构校验仍可通过**；证明它不具备语义支持判断。模型提示词与纠正审核也不是普遍语义证明 |
| 请求／语音／保存失败 | 已有超时、重试、取消、迟到结果、语音失败、存储竞态回归；新增检查服务失败测试 | 原始输入保留，不假装已检查或已保存；不是每种真实网络/设备组合都实测 |

最终 8 个 API 回合中，普通倾听为 1.158 / 2.241 秒；有否认记录的分析/练习为 5.185–11.090 秒。它们是完整 HTTP 回合，**不是首 token、电话首响或 SLA**。这一步为尊重纠正增加延迟与模型费用；正常倾听与电话不增加审核调用。三回合实际触发保守降级，说明稳定性改善以减少分析内容为代价，下一步应改善模型改判能力，而不是隐藏这些失败。

## 工程与界面证据

- 194 项单元/集成测试：入口、来源版本、否认记录限额与清空、一次回应状态、原样重复拦截、审核拒绝/非法响应/失败、最多一次修复、确定性降级、改写保存与导入导出。
- 44 条现有生产浏览器流程通过；本轮手动浏览器检查自然语言生成、有效卡重做与可选方向、改写标识、保存预览、存档恢复。CI 对最终代码再跑类型、构建与同套浏览器流程。
- 传输仍最多 36 KB；否认记录至多四条，请求中至多约 10 KB，超限舍弃最早记录；不会把整段历史无限塞回模型。
- 用户补写不会自动成为新事实来源；“原版依据”不是对补写的背书。

## 复现

```sh
npm test
npm run build
# 在已启动、配置真实模型的本机生产服务上执行；会产生模型调用费用。
BREAD_TASK_APP=http://127.0.0.1:3210 npx vitest run --config evaluations/task-control/vitest.config.ts
```

评估脚本会重写 `actual-results.json`，重跑前自行保留旧文件。只有明确提供 `BREAD_TASK_APP` 才能执行；普通 `npm test` 不包含这组真实调用。前四组记录是迭代历史，不需要重现已淘汰提示词才能检查最终版本。
