# 形成性观察提纲（尚未执行）

目标：3–5 位成年、自愿参与、近期有求职经历的人。当前没有真实参与者记录，以下是执行提纲与空模板，不是调研结果。若没有方便招募的人，提交时明确保留这一缺口。

每人约 15 分钟，可使用虚构材料，不要求公开拒信、公司或姓名；不默认录屏、录音或存储。参与者可跳过、退出或删除本机结果。若需保留具体观察，先说明记录哪些内容并征得同意，使用匿名编号。

主持人先只说：“想象你刚收到拒信，可以只说说，也可以整理一段回答。按你自己的想法使用。”不要先教按钮位置，也不要引导对方说被治愈。

| 任务 | 观察什么 | 中性追问 |
| --- | --- | --- |
| 自己开始 | 是否需要配置、模式或操作解释 | 刚才你以为这里可以做什么？ |
| 想复盘时表达目标 | 自然语言／按钮是否进入期望流程 | 这个结果符合你刚才想做的吗？ |
| 核对一条判断 | 能否找到原话，是否误把解释当事实 | 你会凭什么判断这句话靠不靠谱？ |
| 纠正数字或否认解释后重做 | 是否能找到入口，结果变化是否清楚 | 你期望它接下来怎么变？ |
| 选一个可练的点 | 是否具体、愿意做；也允许不练 | 哪一处你愿意继续，或为什么不想继续？ |
| 保存／放弃／结束 | 是否理解保存范围，是否有被推动的感觉 | 你觉得哪些内容留下了，留在哪里？ |

记录模板（每人一份，未经同意不收集原始材料）：

- 匿名编号／日期／设备：待填
- 是否同意记录、使用真材料还是虚构材料：待填
- 不经提示完成的任务：待填
- 卡住的具体位置与用户原话（经同意）：待填
- 判断准确性／是否可训练的具体例子：待填
- 保存理解与退出情况：待填
- 观察到的问题 → 准备修改 → 再次观察结果：待填

报告保留失败和分歧。不用 3–5 人的小样本推出普遍有效、临床缓解效果或市场规模；不把“完成流程”直接写成“情绪改善”。
