# Community code of conduct

We want people to be able to improve Bread without being judged for their background, language, experience, disability, identity, or personal circumstances.

Be specific and respectful when disagreeing. Critique behavior and evidence, not people. Give credit, respect a person's decision to leave a discussion, and use synthetic examples instead of exposing sensitive conversations.

Harassment, threats, discriminatory abuse, sexual harassment, doxxing, spam, and publishing someone's private information are not welcome. Do not diagnose contributors or use the project to pressure people into relationships or emotional disclosure.

These expectations apply to repository issues, pull requests, discussions, and other spaces maintained for this project. The maintainer may clarify expectations, edit or remove harmful content, close a conversation, or temporarily or permanently restrict participation, according to severity and repetition. Enforcement should explain the behavior and action without republishing private details.

For harassment or private-information exposure on GitHub, use [GitHub's private Report abuse process](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam). For a non-sensitive collaboration concern, open an issue with a short factual description. Security vulnerabilities use the separate [security reporting channel](SECURITY.md). Do not publish sensitive evidence in an issue to request help.
