# Bread hosted runtime

Generated from the [public MIT Bread repository](https://github.com/ZJUZhiyuCai/bread-companion). The application source is shared with the local Next.js version; this checkout adds the official Sites Vinext runtime and a request-scoped Cloudflare D1 admission store.

See the source repository's [deployment guide](https://github.com/ZJUZhiyuCai/bread-companion/blob/main/docs/deployment.md) for configuration, migrations, shared limits, validation and rollback. `bread-source-manifest.json` records the exact application file hashes copied into a generated checkout. No provider secrets or user conversations are part of the source.

The original MIT application license and third-party notices are included. Self-hosted font subsets remain under their bundled SIL OFL 1.1 license.
